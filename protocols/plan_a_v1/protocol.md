# 方案 A 首轮开发协议

2026-10-15，北京时间。依据同日的调研报告与开发指南实施，不修改历史 v1 训练协议或实验产物。

本次会话范围已由用户明确确认：完成实现与小规模验收、保留正式训练配置；不启动三个种子各300轮的长时间正式训练。

数据锁定见 `assets_before.json`。训练只使用原 166 train / Pool A；固定测量验证使用 36 val / Pool A。35 test 不开放。小样本 smoke 取清单前 2 个训练案例，gate 取前 16 个训练案例；它们的结果只用于工程验收。GT64/GT128 不用于训练或检查点选择。

主线 A2 固定 DeepSets sum/4 初始化、32³ lifting、64³ 输出、Q96 中点积分、四步显式梯度、几何行和预条件和共享宽度32三维先验。启用非重入 activation checkpointing 时不截断梯度。外层损失、A/B/H 采样与全局测量尺度沿用指南。内层平方能量按每案例有效射线数归一化。

可实现版本：A0 初始化；A1 仅物理更新；A2 物理更新加共享先验；A3 OARI 初始化；A-control 与 A2 使用完全相同的参数名称、形状和初始值，用残差图的几何提升给学习先验提供信号，Z=C，不调用 Jᵀr。参数匹配不等于计算成本匹配，所有比较另报完整耗时。预条件 none 和 K=1/2/4 是显式消融设置，首轮正式 A2 固定 K4/geometry。

G2–G4 要求先通过 CPU FP64 数值检查，再验证部署 CUDA FP32 和真实两步网络梯度。G5 覆盖乱序、padding、混合V、no_grad及 NaN padding。G6 采用真实池两案例20更新，记录初始/最终损失、独立测量 H、干预响应、显存和文件读取。G7 使用固定16案例与固定测量验证，保留正负结果。正式入口要求同模型、同源码的真实 smoke/gate 通过，合成训练不能代替。

在 G7 尚未开始时，依据 G6 实测耗时登记 `gate_budget_decision.json`：另存5轮/40更新/8验证案例的预算配置，预计约1478秒，仍受1800秒和2000更新上限约束。原80轮配置保留，模型、外层损失与通过条件不因本次预算配置而改变。

验收失败不自动修改尺度、初始化、损失或射线数量。发生显存不足可以启用精确重计算，并建立新配置/运行目录；旧失败记录保留。有限预算未完成的 gate 不登记为通过，不启动正式训练。正式配置为每 seed300 epochs、有效batch2、24900更新；种子20261011/12/13。每个种子与每个消融独立从头训练。

正式模型冻结后，独立评价首先保存全部预测及哈希，再由另一个命令读取 val GT64。默认相同固定测量清单；按案例内几何平均后做 case bootstrap。确认性 test、实测迁移和跨场景泛化需要各自预登记的实验清单，不用工程烟雾结果替代科学证据。
