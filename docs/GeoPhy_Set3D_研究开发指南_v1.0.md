## 1. 开发目标、路线和交付物

### 1.1 最终研究系统应做到什么

输入是同一羽流在若干站位采集的二维路径积分浓度图，以及站位、射线方向和有效性信息。输出是统一物理坐标中的三维甲烷质量分数场 C(x,y,z)，同时输出输入视角重投影、独立留出视角误差和几何覆盖信息。

网络必须接受无序、可变数量的视角。训练和检查点选择不读取三维浓度标签；CFD 体场仅由数据生成与独立评价进程访问。论文主张应限定为“在所测试的视角范围和工况内，相比公平基线改善重建”，不能表述为任意稀疏几何都能唯一恢复。

| 路线 | 本轮定位 | 关键实现 | 启动条件 |
|---|---|---|---|
| 历史 SelfSup-MRGR v1 | 固定参考 | 原始数据、模型、损失和运行记录 | 首先复核 |
| A：集合初始化＋物理迭代展开 | 主线 | 真正的 Jᵀr、几何预条件、共享三维先验 | 投影与高阶梯度检查通过 |
| B：集合条件连续浓度场 | 独立备选 | 三维特征条件化的坐标网络、连续射线积分 | 数据与投影接口稳定 |
| C：非负各向异性高斯场 | 第三候选、表示对照 | 集合预测高斯参数、有限线段解析积分 | A/B 已定位表示瓶颈，且预算允许 |
| D：时空输运约束 | 后续扩展 | 时间、速度、密度及边界条件联合建模 | 存在对应时间序列和物理量 |

建议按 A→B→C 推进，不同时调试四种网络。A 失败并不等于整个研究失败：先区分算子错误、表示误差、优化困难和先验泛化不足，再决定转向 B。

### 1.2 研究完成时应保存的成果

1. 冻结的数据清单、坐标和单位说明、几何文件、统计量、校验和。
2. 历史基线复核记录，以及新增方法的源码、独立配置和必要单元测试。
3. 每次训练的环境、随机状态、日志、最佳/末次检查点和测量验证结果。
4. 冻结的几何与噪声测试清单；每案例、每几何、每随机种子的评价明细。
5. 配对统计结果、失败案例、三维可视化与论文图表生成程序。
6. 推理入口和可复现说明；分别注明单次前向和逐案例优化的成本。

本指南配套的 `方案A_参数草案.yaml`、`方案B_参数草案.yaml` 只用于开发者落实接口及校验规则。先实现新配置验证器，再允许其进入运行状态。

### 2.3 环境落实

历史服务器环境记录为 Python 3.12.15、PyTorch 2.11、CUDA 12.8、RTX 4090。它是复现参照，不是本机已验证可用的环境。仓库 `requirements.txt` 包含本地 wheel 绝对路径，不能直接视作可分发安装清单。

实施顺序：导出服务器实际依赖版本→去除私有临时 wheel 路径并提供可获得的包源/哈希→在新环境安装→运行 CPU 数值测试→运行单 GPU 烟雾测试→冻结可分发环境文件。Linux 参考 C++ 投影器使用编译工具和共享库；Windows 不应假定能直接加载 Linux `.so`。

现有数据加载器在 workers>0 时使用 `fork`。Windows 调试先设 workers=0；若需要多进程，新增并测试 spawn 兼容入口。不得仅把 workers 改为 4 就宣称跨平台支持。

## 3. 数据准备：以现有 Fluent 结果为起点

### 3.1 数据版本和工况台账

当前投影池为 237 个案例：train=166、val=36、test=35；使用第 60 帧，t=2.0 s。历史 148 案例说明属于较早版本，不能混合其数量与当前训练结果。所有数量、成员和分割以当前 `source_index` 与 split 清单为准。

建立案例台账，至少记录 case_id、几何族、泄漏口布局、压力/流量设定、环境风速、CFD 版本、时间戳、导出坐标、变量名称与单位、原文件哈希。工况包含单源、三类双源和两类三源布局。等压工况历史组合为 100/300/600/1000/1500 Pa × 风速 0/1/2/3 m/s；半流量工况为 300/1000/1500 Pa × 0/1/3 m/s。“半流量”指指定孔口质量流量减半，不能写成压力减半。不要据此重新生成笛卡尔积并假定恰好得到 237 个现有案例。

历史 CFD 参数为：SST k–ω，等温 300 K，能量方程关闭，重力 (0,−9.81,0) m/s²，操作压力 101325 Pa，空气/甲烷密度 1.17662/0.65179 kg/m³，分子扩散系数 2.88×10⁻⁵ m²/s，湍流 Schmidt 数 0.7，混合物采用体积加权。扩充数据前应以实际 Fluent case 设置逐项复核；这些参数不能替代网格与时间步收敛证据。

已有 Fluent 模型无需因本指南而重跑。若增加工况，应保留原 train/val/test，并建立新的数据版本；不得为了新方法表现重新分配旧 test。

### 3.2 从 CFD 到投影池的顺序

1. 审计导出场：浓度变量为甲烷**质量分数** C，坐标为米，0≤C≤1，有限值，坐标无重复或异常跳变。越界点先定位来源；不得静默裁剪后掩盖导出错误。
2. 固定重建域 [0,0.6]³ m，采用 XYZ 数组顺序，y 为竖直方向。记录 CFD 原点到重建域的平移/旋转。
3. 将原始非结构网格场按既有流程映射到 128³ 端点网格。保留映射方法、域外处理及原始场，避免只保留最后体素数组。
4. 从 C128 生成投影参考；另从 C128 三线性采样得到 C64，作为评价目标。C64 是节点采样值，不是每个体素的体积平均值。
5. 按案例划分，不按视角、切片或体素随机划分。同一 CFD 实例的帧、增强版本和近重复场不得跨分割；若同一长时间仿真有多帧，用 run_id 分组。
6. 只用 train、Pool A 有效射线建立归一化统计。保留统计所依据的 case_id 列表和哈希。
7. 固定投影池、几何、划分及统计量，之后训练只读。发现数据错误时升版本并重建受影响实验，不能原地修补后继续比较旧结果。

当前投影池重新从 C128 生成测量，没有直接使用原 Fluent 非结构网格路径积分结果。最终建议追加“原生 CFD 网格积分或实测”的独立前向验证；单纯提高同一体素投影器的积分点数，不能完全消除逆犯罪。

实际成员由 `source_index.jsonl` 指定，不能扫描文件夹后自行决定训练成员。每条记录须有唯一 sample_id/case_id、split、generation_status=complete，以及 train_projection_path、ood_projection_path、gt_volume_64_path、source_target_path、condition_meta。后两类体场路径出现在清单里不等于允许训练打开它们。几何文件为 `geometry/train_geometry.npz` 和 `geometry/ood_geometry.npz`；投影文件路径直接从清单解析，并验证最终路径位于数据根目录内。不要根据 case_id 拼出未经核对的文件名。

### 3.3 统一单位、网格与数据类型

| 对象 | 约定 | 开发注意 |
|---|---|---|
| 空间 | [0,0.6]³ m，XYZ，y 向上 | 图像展示、网格采样和导出均保留轴标签 |
| C | CH₄ 质量分数，无量纲 | 主模型输出；不要混成 ppm |
| χ | CH₄ 摩尔分数，无量纲 | 前向测量转换的中间量 |
| Y | 路径积分摩尔浓度，ppm·m | 原始测量至少 float32 |
| C128 节点间距 | 0.6/127 ≈ 4.724 mm | 端点网格 |
| C64 节点间距 | 0.6/63 ≈ 9.524 mm | 不用 0.6/64 代替 |
| 原始 Y 历史最大值 | 85547.742 ppm·m | 超过 FP16 最大有限值，不能先转半精度 |
| 固定归一化尺度 sY | 32284.894580078173 ppm·m | train Pool A 有效射线 p99.5；不是硬截断上限 |
| 掩膜 | bool | 有效零浓度和无效射线不同 |

强度归一化为 y=Y/sY，保留 y>1 的样本。禁止逐视角除以各自最大值，这会丢掉泄漏强度关系。主线先用 FP32；日后使用混合精度时，原始读入、尺度除法、积分及损失累加仍保留 FP32，并与 FP32 基准比较。

### 3.4 训练进程只允许读取什么

白名单：投影数组、站位与射线几何、有效掩膜、训练测量统计、case_id/split 等索引元数据。不要将 `condition_meta` 整体作为网络输入；其中可能有 GT 派生量，必须逐字段审核。训练所用源码不得通过路径间接读取体场。

`assert_no_gt` 可拦截一部分键名，但不能证明文件访问隔离。至少做一次记录文件打开路径的测试，确认一轮训练及测量验证没有打开 GT64、GT128、Fluent 场文件；最好让训练账号/容器根本不挂载这些体场目录。模拟测量本身由 CFD 生成，应在论文中披露；“训练无标签”不意味着数据获取未使用 CFD。

## 4. 站位、扇扫与射线几何

### 4.1 参数固定表

| 参数 | 当前值 |
|---|---|
| 瞄准中心 c | (0.3,0.3,0.3) m |
| 半圆方位 θ | 0°–180°，位于 xz 平面 |
| 水平半径 R | 5.5–6.5 m |
| 站位高度 h | 0.25–0.35 m |
| Pool A / Pool B | 64 / 32 个站位 |
| 每站投影 | 64 行 × 64 列 |
| 水平转角 α | −5° 到 +5°，含端点 |
| 垂直转角 β | −4° 到 +4°，含端点 |
| 图像约定 | 行对应 β，列对应 α |

Pool B 的站位独立采样，但仍来自相同采集范围，不是强几何域外数据。它在历史项目中已经用于 Val-B，不能再称为整个研究从未见过的测试几何。

### 4.2 构造与相交公式

```text
o = c + (R cosθ, h − c_y, R sinθ)
f = normalize(c − o)
r = normalize(cross(f, (0,1,0)))
u = cross(r, f)
d(α,β) = cosβ cosα f + cosβ sinα r + sinβ u
x(t) = o + t d,  t ≥ 0
```

角度参与三角函数前转弧度。对本半圆站位 f 不会与竖直轴平行；泛化到任意三维站位时必须另设退化基向量处理。

用 slab 方法求射线与盒子的 t_near、t_far。平行某轴时，若该轴原点在盒外则无交点，否则该轴不限制区间。最后令 t_near≥0，只有 t_far>t_near 且两者有限才有效。无效射线的 near/far/path_length 写为 0，同时保留 false 掩膜；不能用无穷远或 NaN 参与后续运算。

64×64 为偶数网格，不包含严格 α=β=0 的中心射线。验证中心束时应单独构造解析射线，而不是把某个中心像素误当作光轴。

### 4.3 必须先做的几何检查

- 单位方向范数、基向量正交性；前/后向、盒面、盒角、平行轴和擦边相交。
- 原点在盒内时 near=0；反向指向盒外时无有效正向路径。
- 明确 x、y、z 非对称的三个测试场，例如 C∝x、C∝y、C∝z，以捕获轴交换。
- 以 y 为竖直画站位和射线，再用已知偏移小球检查投影中水平/垂直移动方向。
- 保存有效射线比例分布。当前池整体约 54.2%，只能作为诊断参照，不能作为所有新几何的硬约束。

## 5. 数据接口与可变视角拼批

### 5.1 单分支 batch 的契约

B 表示案例批量，V 表示该分支补齐后的最大站位数，H=W=64。

| 字段 | 形状 | 类型/语义 |
|---|---|---|
| input_projection_raw | [B,V,1,H,W] | FP32，ppm·m |
| input_projection | [B,V,1,H,W] | FP32，raw/sY |
| input_valid_ray | [B,V,1,H,W] | bool |
| input_path_length_m | [B,V,1,H,W] | FP32，域内长度 |
| input_t_near / input_t_far | [B,V,1,H,W] | FP32，射线参数，米 |
| input_ray_direction | [B,V,H,W,3] | FP32，XYZ 单位向量 |
| input_station_origin_m | [B,V,3] | FP32 |
| input_center/right/up_direction | [B,V,3] | 对应字段为 input_center_direction 等 |
| input_station_indices | [B,V] | int64，补齐值 −1 |
| view_mask | [B,V] | bool，真实站位为 true |
| horizontal_angle_deg / vertical_angle_deg | [B,64] | FP32，所有站位共用的角轴 |
| case_id / sample_id | 长度 B 的序列 | 用于审计，不作为网络特征 |
| projection_scale_ppm_m | [B] | 保留尺度元数据 |

新增算子可以先转换成规范几何对象，避免在每个网络里重复拼字段。投影返回值保持 [B,V,1,64,64]，不得在接口外隐式丢掉无效射线而错配像素。

### 5.2 互斥 A/B/H 与采样复现

每案例先选择不重复站位，再分为 A、B、H。训练 A/B 各 3–5 个站位，H=2；总共用到 8–12 个训练站位。网络两次前向分别只见 A 或 B；H 绝不能传入编码器、初始化器或内部物理迭代。推理只使用给定的一组输入站位，无需 B/H。

原采样器以 base_seed、epoch、sample_index、case_id 的稳定摘要初始化随机生成器。复用该实现比重新设计近似采样方式更利于匹配。每个 epoch 创建迭代器前调用 dataset.set_epoch(epoch)；持久 worker 要读到共享 epoch。验证固定 epoch=0，固定 A/B=4、H=4；多套验证组合要单独升级协议，不在训练中随机漂移。

`DualMeasurementDataset` 返回顶层 `{A: batch_A, B: batch_B, H: batch_H}`；H 自己也使用 input_* 字段。它不是存储在 A 的 hold_* 中。三分支 Vmax 可不同，不能用 A 的 view_mask 去屏蔽 H。

### 5.3 编码器输入和掩膜

每站三通道：`[Y/sY, valid_float, path_length/(sqrt(3)×0.6)]`，形成 [B×V,3,64,64]。无效测量先用 where 置零，再做除法/卷积；不能指望 NaN×0 变成 0。

站位 padding 需同时作用于射线、特征、几何提升和融合。所有视角都无效的案例应显式报错；局部体素没有可见站位则允许其融合特征为零，并输出覆盖标志。有效但 Y=0 的射线必须参与损失，它们提供“这里没有明显气体”的约束。

接口验收包括：交换视角顺序输出不变；不同 V 的混合 batch 与逐案例前向一致；加入全 padding 站位输出不变。复制真实站位并不等价于 padding，会改变测量权重，应去重或显式记录重复采样策略。

## 6. 物理前向与数值精度

### 6.1 浓度转换与积分

质量分数 C 到摩尔分数 χ 的关系为：

```text
M_CH4 = 16.043,  M_air = 28.965     （两者采用相同摩尔质量单位）
χ(C) = (C/M_CH4) / (C/M_CH4 + (1−C)/M_air)
C(χ) = χ M_CH4 / (χ M_CH4 + (1−χ) M_air)
Y_r = 10^6 ∫[t_near,t_far] χ(C(o_r + t d_r)) dt
```

在当前二组分假设下使用以上转换。若未来实测背景含水蒸气或其他组分，需重新定义背景气体摩尔质量及仪器量纲。单程/双程光路、是否减背景、路径是否含域外背景，都要由测量协议明确，不能自动乘 2 或默认域外是零。

**计算顺序固定为：插值质量分数 C→转换 χ→沿路径积分。** 先对整张网格转 χ 再插值不与该顺序等价，改变顺序即改变前向模型。

### 6.2 训练投影器与参考投影器

| 用途 | 当前/建议设置 | 说明 |
|---|---|---|
| 现有参考生成 | C128，256 个端点样本，梯形积分 | C++ OpenMP，FP64 累加、FP32 输出 |
| 现有训练 | C64，96 个中点样本 | PyTorch，FP32 |
| A 显式算子起步 | C64，96 中点 | 必须与原训练投影对齐 |
| 积分收敛检查 | 同一 C、Q=48/96/192/384 | 分离积分误差与体场表示误差 |
| 独立物理检查 | 原始非结构网格或实测 | 与同一体素插值器的数值收敛不同 |

每条有效射线长度 ℓ=far−near，t_q=near+(q+0.5)ℓ/Q。训练投影为 `Y≈10^6 ℓ/Q Σχ(C(x_q))`。若每条射线 Q 不同，需保留各自权重；首版固定 Q=96，降低实现分支。

PyTorch 5D 体场使用 `[B,1,D=x,H=y,W=z]`，采样 grid 最后一维必须为 `[z,y,x]`，并按物理域归一化到 [−1,1]。使用 `align_corners=True`，5D 的 `mode='bilinear'` 实际做三线性采样；域内插值采用与现有代码一致的 `padding_mode='border'`。这些约定见 [PyTorch 2.11 grid_sample 文档](https://docs.pytorch.org/docs/2.11/generated/torch.nn.functional.grid_sample.html)。

### 6.3 表示误差与物理失配分开审计

对评价专用案例计算：参考 P_ref(C128)、训练算子 P96(C64)、高积分密度 P384(C64)。三者差异可帮助判断误差来源；其中 C64 是对 C128 的特定采样，不是经过优化的最优 64³ 表示，因此该残差不是所有 64³ 算法不可突破的严格下界。

10 mm 孔口仅约一个 C64 节点间距；6 m 距离的扫描横/纵间距约 16.6/13.3 mm。不能期待仅把输出从 64³ 改为 128³ 就获得相同尺度的真实可分辨结构。必须用小球/双峰可分辨实验和独立测量残差验证细节是否被观测支持。

### 6.4 显式采样算子的接口

建议以固定几何构造三线性稀疏采样：每个采样点保存 8 个节点索引与权重，权重非负、总和为 1。节点扁平索引为 `(ix*N + iy)*N + iz`。端点取下格点时应将 i0 限制在 [0,N−2]，分数在 [0,1]，确保右端点不会越界。

```text
prepare(geometry, N, Q) -> RayStencil
forward(C, stencil, normalized=False) -> projection
jvp(C, v, stencil) -> J(C)v              # 约定为归一化投影的导数
vjp(C, u, stencil) -> J(C)^T u           # 欧氏离散转置，非随意乘体素体积
coverage(stencil) -> T^T 1, T^T(T 1)
```

forward 的单位必须明确；默认给损失的投影是 ppm·m，而 jvp/vjp 服务于下面归一化内层能量。最好使用不同方法名或枚举，禁止用含义不明的布尔值在内部反复切换尺度。

## 7. 主线 A：集合初始化与物理迭代展开

### 7.1 先建立可归因的版本序列

| 版本 | 初始化器 | 迭代内容 | 所回答的问题 |
|---|---|---|---|
| A0 | 集合几何初始化器 | K=0 | 初始化器本身达到什么水平 |
| A1 | 同 A0 | 显式预条件物理更新，无学习先验 | 物理更新是否带来测量/体场改善 |
| A2 | 同 A0 | 物理更新＋共享三维先验，K=4 | 主线方法是否有效 |
| A3 | OARI 初始化 | 同 A2 | 复杂初始化器是否必要 |
| A-control | 同 A0 | 容量匹配的学习式残差回馈 | 收益是否来自物理更新而非额外容量 |

每种可训练版本均从头训练。A0/A1/A2 的共同初始化子网络在同一随机种子下采用同样的参数初始化规则，但不使用已经训练完成的 A0 检查点作为主实验 warm start。需要 warm start 时单列实验。

历史 DeepSets 使用可见特征之和除以固定 V_ref=4，不是按实际视角数取均值。主线 A 初始对齐该 sum/4 方式；“按可见视角均值”是独立消融，避免悄然修改基线。

### 7.2 初始化网络的具体层次

1. 共享二维编码器：Conv2d(3→32,k3,p1)→GroupNorm(8,32)→SiLU→3 个宽度 32 的二维残差块。输入/输出空间均为 64×64；每残差块含两个 k3 卷积，按现有实现落实归一化和激活顺序。
2. 三维提升：在 32³ 端点网格上，将体素位置相对站位的向量投到 f/r/u 基，计算 α=atan2(r,f)、β=atan2(u,sqrt(f²+r²))，双线性采样二维特征。仅 f>0、角度在视场内且 view_mask=true 的位置可见。
3. 初始融合：`F(x)=Σ_v visible_v(x) F_v(x)/4`，得到 [B,32,32,32,32]；另保存每体素可见站位数。
4. 解码：3 个 32 通道三维残差块→三线性上采样到 64³→Conv3d(32→24,k3)→GN(8,24)→SiLU→2 个 24 通道三维残差块→Conv3d(24→1,k1)→sigmoid，输出 C0。

复用的残差块逐层为：Conv3→GN(8)→SiLU→Conv3→GN(8)→与输入相加→SiLU。两个卷积均保持通道数和空间尺寸；二维/三维只改变卷积维数，均不交换物理轴。

OARI 变体才加入已有集合注意力、方向关系与几何条件融合。不要一开始同时改注意力、投影采样、解码器、损失和采样分布。

sigmoid 默认初始化可能输出约 0.5，与稀疏气体尺度不匹配。首轮匹配基线保留原初始化并记录初始残差；若发生明显饱和，可另设“测量幅度初始化”实验：只从训练测量 Y/(10⁶ℓ) 估计路径平均 χ，转 C 并限制到 [10⁻⁵,0.05]，设置输出 bias=logit(C_init)、缩小末层权重。该值只是幅度启发式，不是真实体场均值；对所有匹配模型同样使用，并单独报告。

### 7.3 精确写出内层更新

以下公式按单个案例计算，m 为该输入集合的有效射线数，不能把不同案例直接拼成一个全局 m。r 只包含当前输入 A 或 B；内部更新从不读取 H。

```text
a = 1/M_CH4,  b = 1/M_air
χ(c)  = a c / [b + (a−b)c]
χ'(c) = a b / [b + (a−b)c]^2
χ''(c)= −2 a b (a−b) / [b + (a−b)c]^3

c_rq = Σ_j w_rqj C[idx_rqj]
p_r(C) = (10^6/sY) (ℓ_r/Q) Σ_q χ(c_rq)
E(C) = (1/(2m)) Σ_r [p_r(C)−y_r]^2
g(C) = J(C)^T [p(C)−y] / m

[J(C)v]_r = (10^6/sY)(ℓ_r/Q) Σ_q χ'(c_rq) Σ_j w_rqj v[idx_rqj]
[J(C)^T u]_i = Σ_{r,q,j:idx=i} (10^6/sY)(ℓ_r/Q) χ'(c_rq) w_rqj u_r
```

转置操作通过 scatter_add 累加到节点。这是对离散归一化前向算子的精确 Jacobian 转置，不是“把残差图再做一次几何 lifting”。用于训练的外层损失仍为第 10 节的 robust/self-supervised loss；内层平方能量是提出的新更新机制，二者不必相同，但必须说明。

### 7.4 几何预条件器的定义和限度

定义 T 为上述积分式去掉 χ、直接对采样值求线性积分的非负矩阵。0≤C≤1 时 χ'≤d_max=M_air/M_CH4。采用固定于几何的行和预条件：

```text
D0 = (d_max^2/m) T^T(T 1)
eps_D = max(1e−3 × mean(D0[D0>0]), 1e−12)
D = maximum(D0, eps_D)
update = where(D0>0, g/D, 0)
Z_k = clip(C_k − τ_k update, 0, 1)
τ_k = sigmoid(s_k),  s_k 初值 0，所以 τ_k 初值 0.5
```

若 D0 没有正元素，应判该案例无可用测量，停止处理。D0 可通过一次 T1 与一次 Tᵀ 调用获得，无需显式构造巨大的矩阵。

该 D0 是非负上界 Gauss–Newton 矩阵的**行和对角 majorizer**：先利用 J 的逐元素非负上界，再取其 Gram 矩阵行和得到对角控制；不要把逐元素上界本身误当成矩阵半正定序上界。它不是 diag(JᵀJ) 的精确值，更不是完整非线性能量 Hessian 的全局上界。先验、clip 和残差二阶项意味着本网络没有由此得到全局收敛保证。记录每步输入残差、更新范数与被裁剪节点比例，允许测量残差有小幅非单调；不能以“展开”之名宣称每步必定改善。

首版不启用回溯。若出现数值振荡，再单独研究最多 4 次步长减半的输入能量回溯；接受条件、失败回退、额外投影成本和分支选择是否停止梯度均须固定，不能在测试时临时增加更多迭代。

### 7.5 共享三维先验

主线 K=4，各步使用同一组先验卷积权重。输入共 9 通道：

| 通道 | 定义 |
|---|---|
| 1 | 当前 C_k |
| 2 | 物理更新后 Z_k |
| 3 | tanh(update/0.02)，仅为先验输入压缩，不改变物理步 |
| 4 | log1p(Tᵀ1)/max(log1p(Tᵀ1))，全零时为 0 |
| 5 | 64³ 网格上的可见站位数/真实站位数 |
| 6–9 | 当前步 4 维可学习 embedding，广播到体场 |

结构：Conv3d(9→32,k3,p1)→GN(8,32)→SiLU→3 个宽度 32 的三维残差块→Conv3d(32→1,k1)。末层权重和偏置初始化为零。每步输出：

```text
C_{k+1} = clip(Z_k + 0.02 × tanh(R_theta(inputs_k)), 0, 1)
```

0.02 是质量分数的候选更新幅度，不是物理常数或已证实最优值。先验可以在未覆盖区补值，但这些值应标注为先验驱动。clip 饱和会阻断相应方向梯度，必须统计接近 0/1 比例；必要时研究其他有界参数化，作为独立变体。

覆盖图用于告知信息缺失，不是真实误差图、置信区间或可观测性证明。三维输出可同时返回 C0、各步 Ck、input residual、coverage、τk 以作诊断；正式推理默认只保存必要结果，避免把所有中间体场长期留在显存中。

### 7.6 高阶梯度与推理上下文

反向传播穿过 g(C) 需要对该梯度运算继续求导。如果用 `autograd.grad` 计算内层 g，训练时需要 `create_graph=True`，并在实际部署版本验证所有运算的二阶导数。不能假定一次 backward 成功就说明展开链路正确。官方说明见 [torch.autograd.grad](https://docs.pytorch.org/docs/2.11/generated/torch.autograd.grad.html)。

优先采用固定索引/权重的 gather＋解析 χ'＋scatter 实现 g，让外层自动微分作用于这些基础运算。仍需与小规模自动微分结果对照。几何缓存可以 detach，C、r、χ'(C) 不能为了省显存随意 detach；否则成为截断梯度算法，要单列消融。

显式 g 可以在 no_grad 推理下计算；依赖 autograd.grad 的实现则需要在推理局部 enable_grad，旧验证器外层 no_grad 可能造成错误。固定索引不支持对离散格点选择直接优化站位；若未来做几何自校准，需要重新定义对位置可微的算子。

### 7.7 显存与计算量

4 站×4096 射线×96 采样点×8 邻点，若每邻点存 int64 索引与 float32 权重，共约 144 MiB，不含激活；这是含所有像素的上界。64 站全部缓存约 2.25 GiB，且双分支与多步激活会继续增加。不要把整个池和整轮计算图永久放在 GPU。

起始设置：ray_chunk=256；每块约 24576 个采样点，对应约 2.25 MiB 邻点信息。按站位建立 CPU LRU 几何缓存，预算先设 512 MiB，按需传到设备；几何可复用，依赖 C 的采样值与导数不可跨步缓存。先 profile 再决定缓存级别。

一次 A/B 双分支训练含 2K 次内部梯度更新，以及 C_A/C_B 各对 A/B/H 的外层投影。仅把投影拆块可以减少瞬时张量，但不会自动释放反向传播所需的全部激活。需要时对先验块或查询块使用经测试的重计算；不得通过 detach 偷换算法。

## 8. 备选 B：集合条件连续三维场

### 8.1 端到端实现

继续使用共享二维编码与 32³ 几何提升，融合后用 3 个 32 通道三维残差块得到 F∈R^(B×32×32³)。对物理坐标 x，三线性采样 F(x)，连接归一化坐标和位置编码，经过 MLP 输出 C(x)。主线是一次编码后任意位置查询，不为每个测试案例重新优化网络。

输入向量固定 61 维：F(x) 的 32 维＋归一化 XYZ 的 3 维＋四频带 sin/cos 的 24 维＋2 个覆盖特征。两个覆盖特征采用可见站位比例及第 7 节归一化 Tᵀ1；从相应网格插值到查询位置。位置编码为 `sin(2^l π x_norm),cos(2^l π x_norm)`，l=0,1,2,3，三轴分别计算。

MLP：Linear(61→64)→SiLU→三组 Linear(64→64)＋SiLU→Linear(64→1)→sigmoid，即 4 个隐藏层、每层宽 64。首版四个频带全部启用，保持实现简单；逐步开放频率是后续正则化消融，不能混入第一轮方法对比。

### 8.2 连续投影与体场输出

训练直接查询每条射线的 Q=96 个中点，计算 χ(C(x_q)) 并积分。禁止先生成 C64 再用体素投影器训练，否则失去检验连续表示的核心差异。

为复用体场一致性损失，C_A/C_B 在同一个固定 64³ 端点网格查询，再计算第 10 节 consistency。这是参数与损失对齐的起点；改为随机坐标采样则是另一训练协议。

推理接口分为 `context=encode(input)`、`query(context, xyz)`、`integrate(context, target_geometry)`、`sample_grid(context, resolution)`。缓存 context 只在同一案例推理期间有效。评价 C64 与其他方法公平比较，同时可提供 128³ 可视化，但必须标明其为连续场采样，不能据此宣称分辨率翻倍。

起始 query_chunk=32768、ray_chunk=256。注意分块 forward 之后拼接并统一 backward，可能仍保留全部块的激活；需要依据实测显存使用重计算或设计精确的分块梯度累加。不要独立 backward 后复用已经释放的编码器图，也不要为避错把 context detach。

### 8.3 公平比较与失败判断

B 与 A 共用同一数据、几何组合、外层损失权重、训练轮数、有效 batch 和选模规则。B 的前向表示不同，允许投影实现不同，但必须满足相同物理方程和积分精度门槛。

若 B 仅让输入投影误差更小、留出和三维误差更差，说明表示灵活性可能增加过拟合；优先降低位置编码带宽或加简单平滑先验，不直接增大 MLP。若 B 在同等参数量下胜过 A，论文可聚焦连续表示与集合条件化；若只在 128³ 可视化看起来更细而主指标无改善，不视为成功。

## 9. C/D 扩展的最小可实现规格

### 9.1 高斯场 C：先明确输出变量

建议第三路线先预测摩尔分数场 `χ(x)=Σ_m a_m exp(−0.5(x−μ_m)^TΣ_m^−1(x−μ_m))`，a_m≥0，M=256；在 128/256/512 三档检验容量。此处输出变量与 A/B 不同，导出体场时必须用 χ→C 公式转换。

可用二维特征池化为每站 16×16 token，拼接站位/射线描述；M 个可学习查询经 2 层交叉注意力（d=64，4 heads，FFN=128）得到基元参数。中心 μ=0.6 sigmoid(raw)，标准差范围建议 [0.005,0.15] m，旋转用归一化四元数并在近零范数时回退单位旋转；Σ=R diag(σ²)Rᵀ。幅度采用 softplus。

沿射线 x=o+td，令 A=dᵀΣ⁻¹d，B=dᵀΣ⁻¹(o−μ)，D=(o−μ)ᵀΣ⁻¹(o−μ)，则单基元有限线段积分为：

```text
I = a exp[−0.5(D−B²/A)] sqrt(π/(2A))
    × {erf[sqrt(A/2)(t_far+B/A)] − erf[sqrt(A/2)(t_near+B/A)]}
Y = 10^6 Σ_m I_m
```

只对盒内线段积分，不能用整条无限直线积分替代。实现要处理尾部 erf 相减、浮点负的 D−B²/A、极小尺度等数值问题，并与高密度数值积分逐例核对。先用 FP64 检查，再评价 FP32。

非负高斯和不能自动保证 χ≤1。两种路径只能明确选一种：其一约束所有幅度和≤1，可保证上界，但会限制不重叠局部峰的表达；其二使用有界非线性 χ=1−exp(−ΣaG) 或 sigmoid 场，并改用数值积分。不能既声称任意有界非线性，又继续使用上面线性高斯和的解析积分。软惩罚 χ>1 不构成硬保证，若出现越界不得静默按合法场评价。

### 9.2 时空路线 D：数据满足后再启动

至少需要同一案例的多时刻测量、各束采样时刻、速度 u(x,t)、密度 ρ 或适用的近似、扩散参数以及边界/源项定义。基本约束可从守恒形式出发：

```text
∂(ρC)/∂t + ∇·(ρuC) = ∇·(ρD_eff∇C) + S
```

具体有效扩散和湍流闭合必须与 CFD/物理假设一致。单个 t=2 s 快照不能令 ∂t=0；环境来流风速不能替代完整三维速度。若扇扫期间羽流显著变化，应处理逐束时间，不能把异时观测当成完全同时。

有时序后，可在 B 的查询输入加入 t，按完整仿真 run 分割，用有限差分或自动微分计算残差；先用合成解析解验证，再决定是否增加 PDE 权重。当前静态主线配置中不加入 PDE loss。

## 10. 自监督损失、训练参数和检查点

### 10.1 保持已有外层损失作为首轮公共协议

定义测量差异 d(P,Y)，p=P/sY、y=Y/sY，仅对有效射线计算：

```text
d = mean_valid SmoothL1(p−y; beta=0.01)
    + 0.1 × sum_valid |p−y| / max(sum_valid |y|, 1e−6)
```

先对每案例计算，再对案例平均；不要按射线数把长路径或高视角数案例额外加权。SmoothL1 使用 PyTorch 定义：小残差区为 0.5r²/beta，大残差区为 |r|−0.5beta。

```text
C_A = model(A),  C_B = model(B)
L_hold = 0.5[d(P_H(C_A),Y_H)+d(P_H(C_B),Y_H)]
L_cross = 0.5[d(P_B(C_A),Y_B)+d(P_A(C_B),Y_A)]
L_obs = 0.5[d(P_A(C_A),Y_A)+d(P_B(C_B),Y_B)]
L_cons = mean|C_A−C_B| / [0.5(mean|C_A|+mean|C_B|)+1e−6]
L = 1.0 L_hold + 0.5 L_cross + 0.1 L_obs + 0.05 L_cons
```

两个体场都接收 consistency 梯度，首版不加教师分支、不 stop-gradient。对于全零/接近零测量，relative 项可能敏感；需记录绝对误差与分母，先保持冻结定义做公平比较，再把带噪声底的分母作为独立协议研究。

### 10.2 默认训练设置

| 项目 | 主线起始值 | 性质 |
|---|---|---|
| epoch | 300 | 与历史协议匹配；不因单次好结果提前截断 |
| AdamW | lr=2×10⁻⁴，weight_decay=10⁻⁴ | 公共起点 |
| 学习率日程 | cosine，T_max=300 | 在每完整 epoch 后 step |
| 有效案例 batch | 2 | microbatch=2/accum=1，或 1/2 |
| 精度 | FP32 | 第一轮固定 |
| 梯度裁剪 | 全局 norm=1.0 | 记录裁剪前 norm |
| 随机种子 | 20261011、20261012、20261013 | 新方法正式比较至少 3 个；旧冻结器需独立新运行器支持 |
| 提前停止 | 无 | 保存测量验证最佳与第 300 轮末次 |
| 训练几何 | Pool A；A/B=3–5；H=2 | 首轮不混入困难几何增强 |
| 测量验证 | Val Pool A；A/B=4；H=4，固定采样 | 只根据 held-out relative L1 选模 |

一次 optimizer step 聚合两个案例的平均损失。最后不足累积步数时按实际案例数归一化并完成 step；不能丢弃尾批或再除一次 batch。GroupNorm 不依赖 batch 统计，但累积批与大批仍应做数值对照。

### 10.3 训练主循环伪代码

```text
校验配置、文件哈希、split 和单位；构建只读测量数据集
从头构建模型，设置 Python/NumPy/PyTorch/loader 随机种子
for epoch in 0..299:
    train_dataset.set_epoch(epoch)
    model.train()
    for A,B,H in train_loader:
        检查三分支同 case、站位两两互斥、无 GT、至少一条有效射线
        C_A = model(A); C_B = model(B)
        得到两体场在 A/B/H 的投影；计算四项外层损失
        按累积组的实际案例数缩放；backward
        到达累积边界时检查 finite、clip_grad_norm、optimizer.step
        记录物理步与体场数值统计
    固定验证子集；只计算测量指标
    按 held-out relative L1 更新 best；保存 last 和全部随机状态
    scheduler.step() 并记录下一 epoch 实际 lr
```

scheduler/checkpoint 的保存时刻须一致：恢复时不能多走/少走一次学习率步。每次恢复保存 epoch、global_step、optimizer、scheduler、所有 RNG、loader generator 和采样 epoch；优先支持 epoch 边界恢复，再考虑中途精确恢复。

### 10.4 日志必须回答的问题

每轮记录 total/hold/cross/observed/consistency、留出/交叉/观测相对 L1/L2、lr、裁剪前梯度范数、耗时、峰值显存、C 的 min/max/mean/std、接近 0/1 比例、案例间输出差异。A 额外记录每步 E、更新 norm、先验修正 norm、τ、覆盖为零比例、clip 比例。保存固定案例的测量重投影和中间 Ck，方便检测网络是否忽略输入。

GT 开发评价应由训练结束后的独立工具生成，不进入自动 best 选择。历史开发已经查看过部分 GT，论文应写“训练和检查点选择不使用 GT”，不应夸大成整个研究过程完全 GT-blind。

## 11. 从数学检查到正式训练的验收门

下表为建议开发门槛，并非已通过的模型实验。先从 FP64 小网格建立严格数值对照，再制定 FP32/GPU 容差。

| 门 | 操作 | 通过条件/输出 |
|---|---|---|
| G0 数据 | 清单、划分、校验和、文件读取审计 | 166/36/35 成员一致，训练不读 GT，单位/轴顺序无歧义 |
| G1 几何 | 解析相交、轴向场、偏移球 | 正确方向与路径长度；无效射线 finite 且置零 |
| G2 前向 | 零场、常数场、两种实现对照 | 零场严格零；常数满足 10⁶χ(C)ℓ；CPU FP64 相对误差建议≤10⁻¹⁰ |
| G3 导数 | χ 导数、Jv 有限差分、转置恒等式 | 小网格 FP64 方向差分相对误差≤10⁻⁵；转置误差≤10⁻¹⁰ |

| G8 正式 | 全量、300 epochs、≥3 seeds | 完整运行、协议一致、可恢复与可重放 |
| G9 最终评价 | 冻结模型后读取测试 GT | 每案例明细齐全，配对统计与失败案例可复核 |

Jv 用中心差分 `(p(C+h v)−p(C−h v))/(2h)`，测试 C 远离 0/1，h 先取 10⁻⁶ 并扫描 10⁻⁴…10⁻⁷。转置检查比较 `<Jv,u>` 与 `<v,Jᵀu>`，分母用两项绝对值中的较大者并设置下限，避免偶然接近零时误判。

高阶检查必须覆盖真实的两步网络与物理链路。含 clip/tanh 的模型，在差分测试时选择远离 clip 边界的样本；数值不连续点不能用于证明实现错误或正确。CPU 数值测试通过后，还需部署 GPU 测试，不能直接移植结论。

GPU `grid_sample` 反向可能有非确定性，固定种子不保证跨设备/版本逐位一致；记录环境、给出重复运行的容差，并使用多种子统计。参见 [PyTorch 重现性说明](https://docs.pytorch.org/docs/2.11/notes/randomness.html)。

## 12. 几何测试集与困难程度分层

### 12.1 建立可重用的 geometry_manifest

每条记录包含 geometry_id、站位列表、原点/方向或可追溯几何哈希、V、θ_span、max_gap、有效射线数、覆盖比例、方向张量谱、生成 seed、类别、是否落在训练几何范围。所有方法读取同一清单，不能各自随机抽站位后再比较均值。

对有序方位 θ₁…θ_V，定义 span=θ_V−θ₁；max_gap 默认包括 0 到 θ₁、相邻站位间隔以及 θ_V 到 180°。若只想统计内部间隔，另用 internal_max_gap 字段，避免两个定义混用。V=1 时 span=0，内部 gap 记 NA。

几何方向描述可用 `Q=Σ w d dᵀ/Σw`，d 为有效射线方向，权重先统一为 1；报告特征值、最小值、各向异性等。它描述方向分布，不能称为精确 Fisher 信息或浓度场完整可辨识性。8³ 粗网格算子谱可辅助诊断，但不等价于 64³ 的唯一恢复。

### 12.2 建议的预注册测试矩阵

| 轴 | 建议取值/构造 | 作用 |
|---|---|---|
| 视角数 | 1、2、3、4、5、6、8 | 3–5 为训练主范围；其他值单独标注外推 |
| 自然组合 | 同一池内无放回抽样，每 V 20 组 | 估计常见组合的离散程度 |
| 均匀跨度 | 在允许池中选择最接近等间隔目标的站位 | 避免凭空生成不存在的测量 |
| 小跨度簇 | 目标 span≤30° 或≤60°，每 V 最多20组 | 测试方向冗余；若池不支持则如实记缺失 |
| 双簇 | 两簇中心约分离90°，记录实际角度 | 测试视角数相同但分布不同 |
| 一侧缺失 | 仅使用一个预定半区的站位 | 测试有限角度覆盖 |
| 新站位 | 新 seed 的半圆几何，前向重新生成 | 与既有 Pool B 历史验证区别开 |

20 组为预算起点，不是必须复制 20 次不足以构造的组合。组合应去重并与方法无关。自然/困难分类只能由几何预先决定，不能根据算法误差排序后挑选“困难组”。画误差与连续 span、coverage、方向谱的关系，比只给两个类别更完整。

最终 35 案例在每几何条件下各运行一次；重复组合不是新增独立样本。若进行未见泄漏布局、风速或源强外推，需另建按工况分组的训练/验证方案，并重新训练所有方法；不能把现有随机分割结果直接解释为未见工况泛化。

## 13. 噪声、失配和实测迁移

### 13.1 噪声注入

现有清洁加载器检查非负性。带噪数据在清洁读取之后通过单独 corruptor 在线产生，不修改原投影池，也不为了满足清洁检查而把负噪声值全部截断。

建议先做物理量尺度明确的独立测试轴：

| 类型 | 试验级别（建议） | 实现与记录 |
|---|---|---|
| 加性白噪声 | σ/sY=0、0.001、0.005、0.01 | valid 像素加 N(0,σ²)，保存 seed |
| 乘性测量噪声 | σ_rel=0.01、0.03、0.05 | Y'=Y(1+ε)，与加性分开 |
| 整站增益偏差 | ±1%、±3%、±5% | 每站一个系数，体现相关误差 |
| 零点偏差 | ±0.001sY、±0.005sY | 每站或每帧固定，注明是否已校准 |
| 缺束/缺站 | 5%、10%、20% 射线，或移除1站 | 同步更新 mask；不能把缺失当零浓度 |
| 指向偏差 | 0.02°、0.05°、0.1° | 测量真几何与传给模型的名义几何不同 |
| 站位偏差 | 5、10、20 mm | 真/名义原点分开，不重复扰动 |
| 前向失配 | C128/原生网格；不同 Q | 记录各自离散化 |

这些范围用于灵敏度分析，不代表仪器已经达到或实际具有这些误差。实测阶段应替换为标定得到的噪声模型和范围。

噪声实现按 case_id、geometry_id、noise_id 固定，所有方法共享。先单因素，再选择少量联合误差；不要用全组合大网格消耗训练预算。主比较先清洁训练、带噪测试，之后再研究统一噪声增强训练，匹配对照也应接受相同增强。

生成指向误差时，要由真实射线重新积分测量，向网络只提供名义射线；如果只是同时旋转测量和输入几何，测试的是新几何而不是标定错误。真实/名义射线的有效域交集及缺失处理需预先规定，不能通过测试 GT 给网络补充真几何信息。

### 13.2 真实系统接入前的测量契约

确认仪器输出是否为 ppm·m、路径是否单程、背景扣除方式、谱线拟合和温压校正、饱和与无效标志、站位标定误差、每束时间。若输出是吸光度而非已反演路径浓度，需在当前投影器前增加光谱测量模型，不能直接填入 Y。

验证扫描时长相对羽流变化时间。优先采集几何稳定、浓度变化缓慢的受控案例；把标定场、模型开发数据和最终演示数据分开。没有体场真值时可报告留出路径、独立传感器点值及重复性，不能把这些等同于完整三维真实误差。

## 14. 对比算法、消融和调参预算

### 14.1 必须回答的基线问题

| 基线 | 最低实施要求 | 公平性处理 |
|---|---|---|
| 非负最小二乘/Tikhonov | 与几何一致的前向、明确变量 C 或 χ | 若在 χ 上线性求解，说明插值模型差异并转 C 评价 |
| TV 迭代 | 三轴差分按真实间距；明确 isotropic/anisotropic TV | 超参数仅在开发/验证上选择 |
| SART 类 | 使用实际扇扫三维射线 | 非线性 C→χ 不可当作任意线性体素矩阵 |
| DeepSets / 历史 MRGR | 原实现与公共训练协议 | 保留历史配置，同时给匹配重训 |
| 独立 learned primal-dual/展开网络 | 真正独立结构、同样自监督数据 | 不能只把新方法删一层当全部强基线 |
| INR / DIP 逐案例优化 | 固定迭代数、停机与初始化 | 计算成本单独列出，不能记作一次前向 |
| 监督三维网络 | 清楚使用 GT 训练 | 单独监督组，作为参考而非自监督同类排名 |

如基线直接重建摩尔分数 χ，线性射线矩阵积分 χ 的插值与“插值 C 后转 χ”不完全一致。应披露并尽可能做算子匹配实验；不能让弱基线承担额外模型失配而不说明。

### 14.2 控制变量和建议调参顺序

第一轮锁定全部公共训练参数，只比较 A0/A1/A2/MRGR；单种子完成技术筛选，再对预先保留的方法跑 3 seeds。不要对 A 大量搜索而只给基线一个默认值。

建议依次研究：K=2/4/6→先验幅度 0.005/0.02/0.05→无预条件/所提预条件→sum/4 与可见均值→DeepSets 与 OARI→共享/不共享先验。每次最多改变一个主要因素；先验宽度 16/32/48 和 Q=48/96/192 只在机制确认后研究。Q 首先是数值精度参数，不应靠低积分精度的偶然正则化取胜。

每个方法记录尝试数量、失败配置、选择依据、总 GPU 小时。计算预算采用测量：用少量完整 step 得到时间/显存，再估计完整运行；不要未经 profiling 承诺某张卡一天内完成多少实验。

### 14.3 先写出可被否证的假设

H1：在相同初始化、外层损失和输入下，精确物理更新比容量匹配学习式回馈更稳定地降低留出误差，并改善三维误差。H2：收益在低覆盖/小跨度几何下仍存在，而非只改善自然平均值。H3：适当表示比单纯增大网络更能缓解离散化残差。

预先选择自然组和困难组的主指标。可将“自然组相对改善≥10%，或困难组≥20%且自然组恶化≤3%”作为内部继续投入的候选门槛，但它不是既有结果、统计显著性标准或期刊录用条件。真正的非劣性判断必须依据预定义边界及配对置信区间。

### 14.4 经典对照的可实施起点

为了与主线保持同一物理方程，先实现直接以 C 为变量的投影梯度对照：最小化 `E(C)+λR(C)`，0≤C≤1，E 使用第 7 节归一化测量平方误差。无正则版本取 R=0；平滑版本取三轴有限差分梯度平方的节点平均；TV 版本取 `mean(sqrt(Dx²+Dy²+Dz²+ε_tv²))`，其中 D 含真实节点间距，ε_tv 起始为 10⁻⁴ m⁻¹。记清 R 的平均方式和单位，λ 才有可解释的数值。

采用投影梯度与目标函数回溯：从固定初始化开始，每次用完整输入射线计算目标/梯度；候选步投影到 [0,1]，未满足预定义 Armijo 条件则步长减半，最多 20 次；失败则记录并停止。可用 `F(C_new) ≤ F(C)+10⁻⁴∇F(C)·(C_new−C)` 作为接受条件。起始步长先按初始局部 Gauss–Newton 算子及正则导数估计缩放，记录实际值，而不是给不同变量量纲硬套同一个步长。

预算首先试 500/1000/2000 次迭代；停止规则为相对目标变化连续 20 次低于 10⁻⁶，或达到迭代上限。若未收敛，要报告而不是把未收敛结果当成该类算法上限。λ 在声明的平均/间距定义下先搜索 0、10⁻⁸、10⁻⁷、…、10⁻²；若最优在端点，允许事先记录的一次扩展。所有方法使用统一开发案例和搜索预算。需要保持选参无 GT 时，只用输入站位的内部留出确定 λ，再固定 λ 用完整输入重建；不得用最终测试 GT 挑 λ 或停机轮次。

初始化可比较零场与训练测量得到的固定小幅均匀场，正式基线固定一种。若采用线性 χ 域 SART/TV，应另列其矩阵、归一化和 χ→C 转换，再做与非线性 C 域对照。最终论文无需展示所有调试求解器，但应保留至少一个经过充分调参的传统正则基线。

### 14.5 统一推理适配层

不要为了统一实验强制改写历史模型的 forward 返回值。增加外层适配器，把现有 tensor、B 的连续查询以及逐案例求解器都包装成同一结果结构：

```text
reconstruct(input_batch, output_grid, options) -> {
  field_pred: [B,1,64,64,64],
  field_variable: "methane_mass_fraction",
  axes: "XYZ", domain_m: [[0,0,0],[0.6,0.6,0.6]],
  input_reprojection_ppm_m: [B,V,1,64,64],
  diagnostics: {coverage, iterations, status, ...},
  timing: {load_s, encode_s, reconstruct_s, project_s},
  provenance: {method, checkpoint_hash, config_hash}
}
```

`output_grid` 对 A 是检查网格一致性，对 B 是查询坐标，对传统方法是待求网格。传入网络的 input_batch 不含 evaluation GT。GPU 计时先预热 10 次，正式至少 30 次并在边界同步；首例耗时、稳态中位数和分位数分开。若案例规模有限可以重复同一输入测延迟，但不能把计时重复当成新的重建样本。对逐案例优化，reconstruct_s 必须包括全部优化迭代，不得只计最后一次查询。

## 15. 三维评价、统计与可解释性

### 15.1 指标与数学定义

在相同 64³ 节点上评价，ε 和异常案例处理预先固定。

| 指标 | 定义/注意 |
|---|---|
| 主指标 relative L1 | Σ|C_hat−C_gt| / max(Σ|C_gt|,ε) |
| relative L2 | ||C_hat−C_gt||₂ / max(||C_gt||₂,ε) |
| RMSE | sqrt(mean((C_hat−C_gt)²))，质量分数单位 |
| 峰值误差 | max(C_hat)−max(C_gt)，同时报绝对值和相对值 |
| 峰位置误差 | 两峰坐标欧氏距离，mm；多峰和并列峰规则固定 |
| 质心误差 | 用非负 C 与节点积分权重求质心，零总量记 NA |
| 浓度体积分 | ∫C dV；端点网格采用三维梯形权重 |
| 真质量（可选） | ∫ρ(x)C(x)dV，必须有一致密度模型 |
| 背景泄漏 | 在预定义 GT 低浓度区内的预测积分或 MAE |
| 三维 Dice/IoU（辅） | 固定物理阈值；建议同时报 C=10⁻⁴、10⁻³ 两档，并说明选择 |
| 测量泛化 | 输入和未输入射线的绝对/相对误差分开 |
| 资源 | 编码、重建、投影、逐案例优化、加载耗时与峰值显存 |

浓度和、浓度体积分与甲烷质量不同；单帧 C 也不直接给泄漏源质量流率。若没有速度/密度/边界信息，不输出未经定义的“泄漏量精度”。背景掩膜允许在离线 GT 评价时计算，不允许回传到训练。

### 15.2 逐案例结果与置信区间

明细至少包含 method、checkpoint_hash、seed、case_id、geometry_id、V、noise_id、split、指标、耗时、显存、运行状态。失败/OOM 也要保存，不能静默从均值中删除。

对同一 case、geometry、noise 配对比较方法。主汇总先在每案例内按预定权重平均几何，再对案例平均；同时报告中位数、分位数与最差组。bootstrap 以案例为簇，保留簇内几何相关性，建议 10000 次、95% 区间。若已知多个案例来自同一高度相关 CFD run，应进一步按 run/工况族做敏感性分析。3 个训练种子分别报告，再给跨种子汇总；不要把射线或体素数量当作统计样本量。

### 15.3 可解释性实验应有干预

- A：记录 C0→C1…CK、Jᵀr、先验修正和输入/留出残差。关闭先验、打乱几何、替换/移除某站测量，检查输出的可预测变化。
- 几何：绘制 coverage 与误差的关系；不把注意力图当成浓度真值或可靠性证明。
- 三维性：用不同高度的偏移双团块、倾斜细柱及跨层连续结构；比较联合三维方法与二维逐层堆叠对照。
- 不确定性：多种子/输入子集扰动产生的离散度只能先称“预测分散程度”。如要称置信区间，应在独立数据上检查覆盖率，并报告与误差的校准关系。
- 零空间歧义：展示测量误差相近但三维场不同的案例，说明网络先验在信息缺失处发挥作用。

图中统一物理坐标、色标、等值面阈值和相机角度。至少同时展示 GT、预测、绝对误差、三个正交切片、站位布局和留出投影。禁止逐图自动色标夸大微小变化。

## 16. 按阶段执行的开发工作单

下列“完成标准”决定是否前进；工期按实际 profiling 和问题数量安排，不承诺固定日期。

| 阶段 | 具体步骤 | 必须产生的文件/证据 | 不通过时处理 |
|---|---|---|---|
| P0 资产锁定 | 核对提交、数据清单、训练统计、历史基线结果 | provenance、数据审计、已有/新增模块表 | 先解决版本歧义 |
| P1 几何与算子 | 实现 stencil、forward、Jv/Jᵀu、预条件 | 数值测试、轴向测试、同算子对齐报告 | 不进入网络调参 |
| P2 训练基础设施 | 新注册表、配置校验、GT 隔离、日志与恢复 | 无标签读取审计、恢复等价检查 | 不借旧冻结入口绕过 |
| P3 A 最小版本 | A0→A1→A2，K=1/2 调试后 K=4 | 2 案例烟雾、16 案例 gate、profile | 先排查梯度和尺度 |
| P4 A 正式比较 | 全量300轮，匹配对照，3 seeds | 检查点、测量验证、独立开发评价 | 依据预设假设判定 |
| P5 B 条件启动 | 连续 query/integrate，公平训练 | 表示/积分对照、相同指标 | 无收益则保留负结果 |
| P6 机制与鲁棒性 | 消融、几何、噪声、失配 | 冻结清单、逐案例明细、配对统计 | 不追加挑选性测试 |
| P7 最终盲测 | 冻结方法/检查点/指标后打开 test GT | 最终结果和失败案例 | 新改动需另标探索性 |
| P8 论文与交付 | 图表、方法公式、复现入口、资源账单 | 完整 artifact 包与检查表 | 追踪未完成项 |

开发者首次开工可按以下十步执行：

1. 阅读本指南第 2–6 节，将坐标、单位、mask、A/B/H 数据形状写成断言。
2. 锁定当前数据版本，先复核旧基线配置和历史结果，再计划匹配重训。
3. 用小规模合成场实现显式投影，验证常数场与轴顺序。
4. 实现 Jv/Jᵀu，做有限差分与转置检查。
5. 实现预条件器和无先验单步更新，检查 E 与更新幅度。
6. 接入原集合初始化器，添加共享先验；通过两步梯度测试。
7. 新建训练注册表和配置验证器，保持旧 selfsup v1 不变。
8. 运行无 GT 文件访问测试、烟雾测试及小规模 gate。
9. 依据显存与耗时确定 microbatch/chunk，冻结首轮参数。
10. 才启动全量训练，并在完成后独立评价三维指标。

## 17. 常见故障与排查顺序

| 现象 | 先查什么 | 下一步 |
|---|---|---|
| 一开始投影极大或 Inf | 原始 ppm·m 是否转 FP16、是否重复乘10⁶、C/χ 混淆 | FP32 常数场对照；检查初始化幅度 |
| 体场上下/左右颠倒 | XYZ 与 grid 的 zyx、β 行 α 列、up/right 符号 | 非对称轴向场和偏移球 |
| loss 看似正常但全是近零 | relative 分母、有效零射线处理、梯度断开 | 与零场基线比较，检查各项梯度 |
| A 每一步剧烈振荡 | sY 是否重复除、m 归一化、D0 尺度、τ | 关闭先验，单步/小网格复现 |
| 训练 backward 在展开处报错 | create_graph、部署算子高阶导数支持 | 切换经验证的显式 gather/scatter |
| 验证阶段内层梯度失败 | 外层 no_grad 与 autograd.grad 冲突 | 使用显式 g 或局部 enable_grad |
| 输入误差降、留出误差升 | 过拟合输入、先验太自由、物理失配 | 固定公共损失，检查不同表示与容量 |
| 留出好但三维差 | 稀疏几何歧义、有限案例记忆、GT 坐标错误 | 工况外推、覆盖分层、算子一致性审计 |
| V 改变后输出幅度系统漂移 | sum/4 与均值混淆、padding 参与融合 | 固定汇聚策略并做 V 扫描 |
| batch=1 与 batch=2 差异巨大 | 归一化轴、跨案例展平、mask 广播 | 逐案例对比，检查 m 和 loss 聚合 |
| 显存逐轮增长 | 保存未 detach 日志/中间图，缓存含计算图 | 检查引用生命周期，不靠清缓存掩盖泄漏 |
| Windows worker 启动失败 | fork、入口保护、对象不可序列化 | workers=0；单独开发 spawn 支持 |
| 重启后无法复现下一轮 | RNG、scheduler、loader、采样 epoch | 做保存恢复与不中断运行对照 |
| 所有方法困难组均差 | 几何覆盖与信息缺失、前向误差 | 报告边界，不凭先验补值宣称恢复成功 |
