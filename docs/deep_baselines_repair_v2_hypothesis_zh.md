# 第一个修复候选：仅基于训练测量的读出初始化

在pilot开始前登记。审计显示独立NumPy线性XYZ场与K96物理投影的最大差1.82e−12 ppm·m；FP64 AD/FD相对差5.49e−13；两例零场H L1均为精确1。零场体素梯度绝大多数为负，故“测量loss完全没有向上梯度”被排除；在正的均匀场C=.001处总方向导数转为正，说明缺少空间结构时缩小整体输出可降低loss。未发现单位、轴序、掩码或优化器步数错误。审计的通用文字标签不是数值结论：在精确零场，正体素梯度数实际为0，不能称该点存在背景正梯度。

fresh DeepSets/GNOT在固定train0/1上输出均值0.4983/0.3740，而从全166例train的epoch0合法A/B测量闭式估计得到mass fraction0.004195626187323315，bias−5.4695082277569576。估计只含2,977,913条有效训练射线，含有效零，不使用GT汇总/val/test，也不借用历史Senseiver或主模型权重。

旧300轮日志和best checkpoint显示深负logits（DeepSets中位−36.51、GNOT中位−25.09）。失败权重的weighted consistency梯度约8.43e−9/1.32e−7，而hold约1.10e−13/2.41e−8。consistency分母固定1e−6在极小浓度时使共同缩放损失趋零，可能助长停留在近零场；这是需要下一步受控验证的次级机制，当前不改loss、不宣称已证实全部训练因果。

**本候选只改变新版本末层weight×.01与bias初始化，保留phi/attention/几何门控/坐标decoder、sigmoid、全部原loss及优化设置。** 预期初态回到合法测量支持的数量级，减小早期全局压低/clip；若pilot仍趋零或验证不优于零场，则初始化不足，不启动该候选300轮。构造器不加载任何数据/权重，浓度只来自独立审计登记的训练测量统计。

验收沿用预登记协议：固定32train/完整36val，先10轮；只有明确趋势才延长，最大30轮；最后连续两轮H<=.99，且通过非零/跨案例/输入干预H收益与工程检查才GO。DeepSets/GNOT分别判断。旧4train/2val/10update工程pilot被误作正式准入的证据不足，本轮以科学门槛纠正，不再把“工程可运行”当有效学习。
