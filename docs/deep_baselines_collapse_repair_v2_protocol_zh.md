# DeepSets / GNOT 测量自监督塌缩诊断与有界修复协议

登记时间：2026-10-24；用户授权来源为本轮粘贴任务。基准仓库commit为871f451。旧训练队列继续暂停；不恢复第二种子，不启动Senseiver，不再访问35案例测试结果挑选修复。

## 阶段A：先审计再决定修复

只读原DeepSets/GNOT seed20261011的无GT best checkpoint、train/val合法测量及元数据。核对ppm·m、Y_SCALE、有效零射线和padding、A/B/H不交、XYZ/米/K96、独立NumPy线性XYZ场投影、FP64物理链路AD/FD、零场与局部体素梯度、四分项梯度与夹角、fresh/failed logits和测量响应、旧epoch日志及优化器恢复记录。冻结Plain代表性CPU输出回归使用现有锚点。

尺度假设：logit0约0.5质量分数可能使网络先压低所有空间输出并进入负饱和；仅是假设，需实际日志与梯度支持。另检查有效近零射线对空间均匀预测的压低方向、consistency与观测学习梯度的竞争。不得从GT统计或历史测试成绩设定浓度先验。

任何浓度初始化只能从全166个train案例epoch0合法A/B测量闭式估计：chi=Σ(length*y)/(1e6 Σlength²)，然后精确转换为质量分数；不使用val/test或GT统计。已有train_statistics.json用于冻结的投影归一化元数据，包含的历史GT汇总字段不作为修复输入。

## 修复与pilot的有界安排

先审计，后为每项候选单独记录因果假设、改动、预期及来源。最多两种有根据的修复版本/模型，不做宽度/LR/seed扫描。第一个候选优先只改变独立基线读出初始化，完整保留原架构、输出物理定义和统一loss；如果证据不支持此项则重新记录选择依据。只有梯度证据支持时才登记第二个候选，不自动删除loss。

每个模型/候选使用fresh seed20261011，固定train前32例、全36例val、完整64³与K96、全部有效射线（包括零）、batch2/AdamW2e-4/wd1e-4/clip1/FP32/cosine T_max300。pilot loader设workers0便于完整访问审计，不改变样本及数值目标。每轮重采样train至该epoch，val固定epoch0。初始10轮/160更新；仅在近5轮val H4改善至少0.005且没有塌缩时允许继续，硬上限30轮/480更新。未通过且没有趋势则停止该候选。

科学GO要求同时满足：最后连续两轮完整val H4 L1 <=0.99，较未训练模型至少改善0.01；输出mean>=1e-8且<1e-10的体素少于95%；跨案例相对差>=1e-3；固定val前4例的测量置零干预中至少2例浓度relative MA>=1e-3、且正常观测的H4 L1优于置零观测至少0.001。健康诊断不更新权重，不用GT。不是仅有梯度非零、loss有限或输入有数值响应就GO。

每候选必须通过工程smoke、有限梯度/真实更新、checkpoint与AdamW/cosine/RNG往返、掩码/排列不变性/分块等价及主模型回归。原失败结果与源码原地保留，修复放新文件、新配置、新scratch目录。

## 有条件的正式训练

仅GO模型允许从fresh seed20261011进入全166train/36val、300轮/24900有效更新。保持原训练设置；若有必要的损失改变，须在相应候选配置内明确登记，不能称原协议完全相同。不启动第二种子。独占GPU0全局UUID锁、15秒双空闲快照、资源门槛和冲突处理沿用现有controller；GPU1–3不使用。

正式训练监控规则提前固定：从epoch5起每5轮健康检查；若连续3次同时满足val H4>=0.999且输出均值<1e-8或95%体素<1e-10，判持续塌缩并保留完整checkpoint暂停；或epoch30后连续3次val H4>=0.999且不再优于初始val/无有效测量依赖，判学习失败暂停。非有限输出/梯度/状态直接工程停止。禁止把提前终止记为300轮完成。完整epoch原子checkpoint为恢复权威，保存optimizer/scheduler/RNG/loader/best/metrics，不自动重试冲突。

若尚在正式训练，报告准确epoch/更新和best/last哈希、监控状态及复查入口；不声称已完成。若两候选均不通过，归档NO-GO并报告剩余不确定性，不扩大搜索或启动正式训练。所有GT64/GT128、Pool B和测试测量数组均禁止，原冻结模型/失败结果哈希在末尾复核。
