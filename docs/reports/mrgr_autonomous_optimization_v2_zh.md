# 多尺度 MRGR：第二轮自主优化记录

启动日期：2026-10-17（北京时间）；完成日期：2026-10-18（北京时间）。用户授权调研、并行测试至少四种新方案，对合适候选完成300轮正式训练及最终重建评价。本文持续记录实际结果，不以已启动代替已完成。

## 1. 起点与问题

当前正式多尺度MRGR为344,678参数、300轮、seed20261011，普通V4三维相对L1为9.3697%、聚簇五布局为33.0012%。原正式来源/数据清单与权重已经核验。本轮保留所有旧源码、检查点、日志和报告。

上一轮固定O嵌入OCMSF不及同容量非条件融合。非条件融合20轮普通投影均值有3.48%相对收益，但仍需新种子复核。此前相同初始状态/样本序列的训练执行曾有明显漂移，小幅单次收益不能直接解释为结构因果。

主要假设：尺度融合可能有用，但固定几何注入强度可能干扰内容特征；学习率可能限制短程优化；跨输入场一致性可能与稀疏角度下的投影拟合竞争。不同假设分别实验，避免多项改变叠加后无法归因。

## 2. 预定路线与资源

启动时GPU1/2/3均为RTX4090、利用率0%、显存约1MiB。GPU0有驻留任务，本轮分配不使用GPU0、不终止其他进程。各卡上的训练臂依次运行。

| GPU | 路线 | 新候选/对照 | 关键变量 |
|---|---|---|---|
| 1 | 可学习几何融合 | 原多尺度、参数量匹配内容融合、可学习O融合 | 用零初始化5→3可学习logits替代固定几何嵌入；两融合候选参数相同 |
| 2 | 参数优化 | 原多尺度、LR=4e-4、一致性权重=.01 | 两候选各只改一个变量，基线LR=2e-4/一致性=.05 |
| 3 | 尺度融合简化与复核 | 原多尺度、空间内容融合、全局尺度softmax | 新全局3权重；空间融合做新种子重复 |

参数量匹配不代表函数空间完全匹配：几何路线内容控制的额外线性head可代数折叠进原内容logits，而几何head引入不同输入。因此即使参数相同，也不能将差异严格归因于“几何信息本身”；本次因困难布局退化未晋级。

新增方案至少四种：可学习几何融合、提高学习率、降低一致性权重、全局尺度融合；另独立复核已有内容融合。可学习几何路线的容量匹配内容控制也是单独记录的结构变体。

第六条另行补充预注册：共享权重的两步MRGR反馈。每步用当前场重新计算输入投影残差，第二步继续更新context并共享原编码器/adapter/fusion/decoder，不增加参数。若GPU1的几何候选未晋级，则接续两步反馈的独立两臂短筛；若几何候选晋级，优先完成其重复，双步只先做CPU准备。该路径有意增加一次物理迭代，运行前单独登记允许完整轮成本增加至50%、同时300轮仍须≤5小时，其他面板门槛不变；不是看到结果后放宽其他模块的20%成本门槛。见[补充登记](../../outputs/research/mrgr_autonomous_optimization_v2/two_step_supplement.json)。

每臂完整166训练/36验证、20轮、1,660更新；第一种子20261018，合格候选再用20261019配对复核。模型与数据采样共同使用该种子，因此不同种子的验证站位会改变；每个种子内严格匹配，不将跨种子绝对均值直接归因结构。

原Q96投影器、数据划分、归一化、AdamW权重衰减1e-4、batch2、clip1和300轮余弦前缀不变。损失权重实验另记原权重的standard_total；模型比较与选模仍使用留出H投影相对L1。

## 3. 筛查、复核与正式训练判据

各路线在优化前独立登记源码/数据/配置hash和晋级门槛。首轮要求固定第20轮普通H均值相对降低至少1%，普通P90和聚簇五布局案例均值恶化不超过2%，每轮成本增幅不超过20%，300轮估时不超过5小时，并通过正确性、有限性与GT读取审计。

通过者做独立第二种子配对复核。主agent将综合两种子的效应方向、均值/P90/困难面板与成本，再封存正式候选决定。若两次方向相反、退化超限或收益仅在单次末轮出现，保留为不确定或未晋级，不强行长训。案例bootstrap只描述案例差异，不覆盖训练随机性。

正式训练最多同时安排三个任务，优先一个结构候选、一个独立参数候选及必要的新执行基线；不事后把多个改动组合成未经筛查的候选。正式种子优先20261011，与已有正式模型协议匹配。全新初始化，300轮/24,900更新，按原最低验证H选择checkpoint，支持完整状态显式恢复。

在查看新三维GT评分前，封存所有晋级决定、正式权重和各模型的全部预测。随后独立评价同一17布局×36验证案例，报告三维相对L1/L2、P90、峰幅/峰位、质心、Dice和背景泄漏，并展示预先固定案例的同切面/同色标图。开发验证结果不称盲测；最终35例test保持不用。未补齐时序与流场前，不加入未经验证的稳态PDE约束。

## 4. 调研依据与适用范围

- [Learned Primal-dual Reconstruction](https://arxiv.org/abs/1707.06474)：将前向算子纳入学习迭代，为保留现有MRGR测量反馈提供方法动机；论文中的CT收益不能迁移成当前气体数据的收益承诺。
- [Decoupled Weight Decay Regularization](https://arxiv.org/abs/1711.05101)：学习率和AdamW正则应分别审视。本轮先保持weight decay固定，只测试一个明确学习率，避免无界网格搜索。
- 当前仓库的[完整重建测试](mrgr_multiscale_completed_model_test_zh.md)、[上一轮三路线](mrgr_parallel_optimization_20261017_zh.md)、[OCMSF四组筛查](mrgr_ocmsf_screening_zh.md)是主要问题证据。尤其保留投影改善未必带来三维定位改善、极窄布局仍失败的限制。
- 既有[64³表示审计](representation_capacity_64_v1.md)还显示：12个训练场从GT64初始化、仅按16站投影优化后，拟合投影L1下降，但体场相对GT64的L1差异均值达到8.55%。这是不同预算/先验下的有限诊断，不能当作网络误差下界；它说明当前参考投影来自128³，而重建在64³上，测量拟合也可能补偿表示失配。此次没有重新打开GT数组或把该诊断当作选模监督。

### 5.8 筛查阶段的机制解释与边界

| 路线 | 目前证据支持的判断 | 尚不能推出的结论 |
|---|---|---|
| 可学习几何 | 普通与聚簇方向相反，当前几何logits注入没有稳定改善跨布局表现 | 不能据一个注入方式否定所有几何条件化；同参数量控制也不是严格相同函数空间 |
| 全局/内容尺度融合 | 新全局融合失败；原内容融合的小收益未被新种子重复支持 | 不能把旧有单次小收益写成稳定结构贡献，也不能把所有退化都归因于CUDA漂移 |
| 降低一致性权重 | 普通H改善伴随聚簇退化；原权重重组损失反而更高，体现目标权衡变化 | 较小实际total不等于更佳重建；固定两例梯度探针不能证明总体因果 |
| 幅值校准 | 普通例全部选择倍率1，当前全局幅值校准没有普通收益 | 不代表局部峰幅、位置或背景问题已解决，也不排除更细倍率有用；本批不事后扩网格 |
| 两步反馈 | 分支与梯度真实有效，普通收益较大但聚簇更差；当前第二步没有提供稳健增益 | 与弱观测下误差反馈放大相容，但未单独验证其机制；不等于所有多步方法无效 |
| LR4e-4 | 两次短前缀配对改善可重复，参数量和单轮成本不变，适合做正式验证 | 20轮收益可能仅是更快收敛；不能预言300轮终态或三维L1/L2收益 |

这些结果首先说明普通布局拟合与困难布局稳健性必须一起看，而非证明气体重建已达到精度上限。稀疏观测的弱约束方向、128³参考投影与64³表示之间的失配、局部高峰与低浓度背景的权衡，仍是已有证据支持的后续诊断方向。可靠时序/速度/扩散及边界资产未对齐前，不用任意稳态PDE损失代替验证。当前批次按预先规则完成正式三维评价后收束，不根据新GT结果继续试参。
