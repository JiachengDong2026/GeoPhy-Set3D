# Ray-GNOT-v1 独立实现与射线积分适配记录

本模型是 Hao 等人 GNOT（ICML 2023）的射线积分逆问题适配，名称为 **Ray-GNOT-v1**。它保留异构归一化线性算子注意力、全局查询自注意力和几何门控专家网络；不能将本任务结果描述为原论文点值算子任务的直接复现。实现不使用主模型的 GeometryLifting、MRGR、融合或 PRF，不修改其冻结源码。

## 输入与输出

统一入口为 `geophy_set3d.models.baseline_gnot_v1.RayGNOTV1(**settings)`，`forward(batch)` 返回 FP32 `[B,1,64,64,64]` 的 CH4 质量分数，经 sigmoid 约束在 `[0,1]`。XYZ 三轴均使用 `[0,0.6] m` 端点节点，顺序与冻结主模型一致。

复用既有 `ray_senseiver_ss.ray_tokens` 作为非学习型打包器，不复用 Senseiver 或主模型的可训练表示。每个合法射线的 203 维特征为：1 维积分测量、3 维入口、3 维出口、3 维方向、1 维路径长度和入口/出口各 96 维 Fourier 特征。测量标尺固定为既有训练统计 `32284.894580078173 ppm·m`；入口/出口归一化到 `[-1,1]`，长度除以盒体对角线。有效性取 `input_valid_ray AND view_mask`，保留积分为零的有效射线。

异构输入分为两个独立 MLP 分支：测量分支使用完整 203 维特征，使积分与对应几何保持关联；几何分支使用去除积分后的 202 维特征。两者都只包含相同合法观测，不读取留出测量、GT 或完整体标签。几何分支是相同输入信息的重新编码，不增加观测。有效射线数为零时，打包器的占位 token 会被额外排除，输入算子贡献为零；此时仍有坐标分支和网络偏置的无观测预测。

## 保留的 GNOT 核心

每个算子块依次执行：异构跨注意力、第一组几何门控专家、全局查询自注意力、第二组几何门控专家，含相应残差和 LayerNorm。两种注意力均将每头的 query/key 在**特征维** softmax，使用以下归一化算子，而不是普通的 token 维 softmax Transformer 注意力：

`A_s(q) = q (Σ_j k_sj ⊗ v_sj) / (q · Σ_j k_sj)`。

异构跨注意力对两个来源分别归一化后求和，并保留 GNOT 的 `q` 附加项；自注意力保留相同的归一化与附加项。几何门控只接受输出查询的 XYZ，三层坐标 MLP 的 softmax 权重对两个专家 FFN 作加权平均，对应 GNOT 的软域分解思想。

原论文学习由输入函数/边界/参数到 PDE 解的算子；本适配学习由稀疏射线积分集合到浓度场的逆映射。分支语义和输出 sigmoid 是任务必要适配，输出网格并非原论文的图数据接口。不能把射线积分视作射线某个端点处的浓度点测量。

## 配置与成本边界

冻结候选配置位于 `configs/baselines/gnot/model_v1.json`：宽度 64、2 个算子块、4 个注意力头、每组 2 个专家、专家中间宽度 256、查询块 8192、训练激活 checkpoint。实际参数 **527,109**，FP32 参数张量 **2,108,436 bytes**；不含优化器状态、运行激活或 checkpoint 容器元数据。

采用 PyTorch Linear 默认随机初始化，最终输出 bias 固定为中性 logit 0，不引入浓度先验、不使用 GT 选择输出尺度。本轮没有进行网络宽度、专家数或输出初始化搜索。

`64³=262144` 个输出查询不构造平方注意力矩阵。跨注意力先计算每个输入分支的 `Σk` 与 `Σ(k⊗v)`；自注意力则先在**全部查询块**上计算全局同类统计，完成归约后再逐块应用。分块不会把全局算子变成局部算子，误差仅来自浮点求和顺序。自注意力复杂度随查询数线性增长，仍需保存或重算查询特征；分块 checkpoint 减少专家中间激活，不能保证所有 batch/卡型都具有相同峰值显存。

单次 CPU 可行性记录：2 线程、默认完整宽度模型、1 样本 17 个合成射线 token、完整 64³ 查询、无梯度，耗时 **3.333 s**，进程峰值 RSS **869,608 KiB**，输出有限，范围 `[0.39415,0.61943]`。这是未训练随机模型的合成工程检查，非真实数据精度、正式推理成本或 GPU 显存基准。真实物理损失、GPU 峰值显存、训练速度和正式推理速度由统一集成阶段记录，本文件不填入估计值。
