# 多尺度 MRGR＋轻量局部细节分支：条件晋级实验

登记日期：2026-10-16（北京时间）。用户授权短程测试通过后开展300轮训练及模型评价；GPU3另行进行反馈控制探索。本报告的启动记录不是训练完成或效果改善的声明。

**后续状态：两组20轮筛查已完成，普通H均值相对改善1.05%、聚簇五布局改善2.90%，但普通P90恶化4.78%，未通过预注册的2%尾部退化上限。流水线已停止，未启动300轮或GT三维评价。完整结果见[短程筛查报告](mrgr_local_detail_screening_zh.md)。**

## 1. 架构与对照

以已完成正式训练的多尺度MRGR架构为基础，保留OARI、GCA、测量残差反馈、16³/8³上下文和原测量自监督目标。在共享解码器第三个32³残差块后，与上下文分支并行增加局部路径：32→8通道，3³深度卷积，8→8逐点卷积，8→32零输出卷积。C0/C1共享该解码器。

参数从344,678增至345,574，增加896（约0.26%）。这是32³特征上的局部建模，不是128³重建，也没有使用GT位置选择局部区域。上下文与局部两分支均由测量目标学习，局部路径能否改善源峰需要后续三维评价确认。

## 2. 公平性与正确性

两组同seed20261011全新初始化；共享张量完全相同，新局部分支输出卷积零初始化。CPU解码及GPU完整模型初始输出逐位一致。smoke完整目标前反传三次，无优化器更新；新增输出层梯度非零且有限，权重未变，GT/禁止NPY/外部权重读取尝试为0。

GPU0预热后完整目标前反传：原多尺度约0.3478秒，局部版约0.3534秒；峰值allocated显存7.23/7.30GiB。这里只是短测，未包含优化器、完整验证、I/O及后续共享负载，不能作为300轮实际时间。

## 3. 预先固定的晋级条件

两臂均用166个训练案例、36个验证案例，各20完整轮，83更新/轮，FP32、batch2、AdamW与原损失不变，学习率为300轮cosine前缀。

固定第20轮评价，不在多个轮次或布局中挑选最好结果。普通H为每案例A/B两次重建留出误差的均值；聚簇沿用已冻结五布局，先案例内平均，再对36案例汇总。

晋级必须同时满足：

- 普通验证H相对L1至少降低1%。
- 普通逐案例H的P90不恶化超过2%。
- 聚簇五布局H均值不恶化超过2%。
- 同卡两组第3–20轮平均训练及验证耗时比不超过1.20。
- 依实测完整轮外推300轮不超过5小时。
- 正确性、梯度有限性及零GT读取检查通过。

这是单种子短程测量筛查，不证明最终三维优越；配对区间仅反映案例变化。未通过时自动停止，不追加同配置300轮。通过时从局部版第20轮的完整优化器、调度器及随机状态准确接续至第300轮，不重置学习率；最优权重仍仅按原固定验证H选择。

## 4. 正式训练后的评价

正式训练完成且权重封存后，复用原17布局×36验证案例、相同站位和64³节点。先由无GT进程保存C0/C1共1,224场，再由独立进程评分L1/L2、P90、峰幅/真实峰位置、质心和Dice，并与历史、原多尺度及A/B配对比较。报告使用此前固定三例的同切面、同色标，不按新模型表现挑例。

当前35个最终test案例保留；本轮与此前模型比较保持验证开发评价口径。源代码、旧权重和旧评价结果均不改写。
