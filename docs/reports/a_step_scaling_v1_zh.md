# A 后两步物理位移缩放：冻结模型诊断 v1

完成时间：2026-10-16 10:59（北京时间）。本实验属于已公开验证集上的机制诊断，不是新训练模型或最终独立测试。

## 结论

**减弱后两步物理位移，在极窄聚簇布局上带来一致但小幅的改善，在普通布局上带来小幅退化。当前证据支持存在几何相关的权衡，但不能把 A 与历史模型的困难组差距主要归因于这两步，也不支持直接删除后两步。**

在预先固定的四个全局缩放中，缩放为 0 时困难组三维相对 L1 从 56.7503% 降至 55.7250%，相对下降 1.81%，34/36 个案例改善；普通组从 9.0734% 升至 9.1313%，相对增加 0.64%，30/36 个案例变差。困难组仍明显差于历史模型 43.9439%。

## 协议与边界

- 使用已冻结的 A 第 299 轮最佳检查点，SHA256 `cc33c1bbc16d9a424e948ca129defa7162e9c205f25fcada1736d939107a7238`，参数完全不变。
- 复用先前已保存的第 2 次先验后的 FP32 状态 `C2`；输入为原有 36 个 Pool A 验证案例、相同站点及顺序。普通 `Val-A-V4` 与 `clustered-V4 draw0` 共 72 个案例布局。
- 预测前注册四个全局缩放 `0、0.25、0.5、1`，同时作用于第 3、4 次物理位移：`z = clamp(c - scale * tau * update, 0, 1)`。前三个因素中的 `c`、`update` 继续随各自轨迹演化。
- 学习先验、步嵌入以及先验输入中的 `tanh(update/.02)` 均保留原规则。因此 scale=0 只使两次物理位移精确为零，仍计算反馈，且两个学习先验继续执行；这不是删除整个迭代块。
- 每个案例的留出投影站点固定，四个缩放完全一致，并与先前机制实验留出站点逐例核对。本次 H 面板与正式模型测试报告的 H 面板不同，不能把两份报告的 H 均值直接比较；本次各缩放之间可配对比较。
- 全部 288 个三维预测保存并记录哈希后，另一个进程才读取验证 GT64。预测阶段 GT 打开和尝试均为 0。没有读取最终 test，没有逐例使用 GT 选缩放，也没有修改检查点选择规则。
- 历史对比读取原来相同案例、相同输入布局的已存指标。所有冻结模型源、检查点和既有 manifest 均未修改，仅新增独立实验脚本和结果目录。注册后、预测前仅修正了历史 JSON 字段读取方式，注册文件保存了该评分修正的时间、原因和前一脚本哈希，四个缩放及协议不变。

## 三维结果

下表为逐案例宏平均；百分数表示相对 L1，P90 是 36 个案例误差的 90% 分位数。胜/负以此次同面板 scale=1 为参照，越低越好。

| 布局 | 后两步缩放 | 平均相对 L1 | P90 | 对原 A 胜/负 |
|---|---:|---:|---:|---:|
| 普通固定四视角 | 0 | 9.1313% | 14.3785% | 6 / 30 |
| 普通固定四视角 | 0.25 | 9.1126% | 14.3575% | 8 / 28 |
| 普通固定四视角 | 0.5 | 9.0958% | 14.3381% | 10 / 26 |
| 普通固定四视角 | 1 | 9.0734% | 14.3084% | — |
| 极窄聚簇四视角 | 0 | 55.7250% | 68.0847% | 34 / 2 |
| 极窄聚簇四视角 | 0.25 | 55.9701% | 68.0095% | 34 / 2 |
| 极窄聚簇四视角 | 0.5 | 56.2237% | 67.9202% | 34 / 2 |
| 极窄聚簇四视角 | 1 | 56.7503% | 68.3054% | — |

历史 MRGR 在普通组为平均 9.6193%、P90 15.7416%；极窄聚簇组为平均 43.9439%、P90 58.7065%。scale=0 的困难组仍比历史模型误差高约 26.81%，胜/负仍为 8/28。

scale=0 对 scale=1 的逐案例平均差：普通组 **+0.05785 个百分点**，95% 配对 bootstrap 区间 `[+0.02637, +0.10174]` 个百分点；聚簇组 **−1.02531 个百分点**，区间 `[−1.29038, −0.77094]` 个百分点。使用 10,000 次案例级重采样、种子 20261016。这是当前 36 个案例及既定布局下的描述，不是对新布局、多种子或独立测试的保证；四缩放面板是探索性诊断。

## 投影结果与机制解释

| 布局 | 缩放 | 输入投影相对 L1 | 留出投影相对 L1 |
|---|---:|---:|---:|
| 普通固定四视角 | 0 | 1.9099% | 3.0226% |
| 普通固定四视角 | 0.25 | 1.8721% | 3.0018% |
| 普通固定四视角 | 0.5 | 1.8355% | 2.9813% |
| 普通固定四视角 | 1 | 1.7782% | 2.9493% |
| 极窄聚簇四视角 | 0 | 8.8320% | 32.6828% |
| 极窄聚簇四视角 | 0.25 | 8.1449% | 32.6350% |
| 极窄聚簇四视角 | 0.5 | 7.6022% | 32.6312% |
| 极窄聚簇四视角 | 1 | 6.9675% | 32.7296% |

普通组中，原物理位移强度对三维与投影都更有利。聚簇组中，输入投影拟合更好的 scale=1，其三维误差却更高。因此仅凭输入投影误差降低来接受步长，无法保证三维改善。动态更新值得进行匹配短程验证，但应视为待检验假设。

本实验只缩放物理位移，没有重新训练先验，也没有缩放反馈信号。干预改变了先验的 `c/z` 输入分布；先验可能原本就与固定步长共同适配。这意味着减步的小收益既不能证明动态步长重新训练一定有效，也不能证明其效果上限仅有 1.81%。其他初始化、空间先验和几何消歧因素仍可能更关键。

## 正确性与成本

- 72 个 scale=1 最终场均通过与归档 C4 的一致性检查：逐体素最大差的全组最大值 `0.00018826`，逐场平均绝对差的最大值 `0.0000014167`。
- 每组首个案例还执行了完整四步前向，与 C2 续算进行核对；最大差分别为普通组 `0.00011884`、聚簇组 `0.000036031`，符合预注册容差。跨卡 BF16 网络执行和已存中间态的数值扰动可产生微小差异。scale=1 平均三维 L1 与正式测试基准分别只差约 `−0.000132`、`−0.000154` 个百分点。
- scale=0 的第 3、4 步实际物理位移最大绝对值均严格为 0，两个学习先验仍运行。
- 使用物理 GPU2（RTX 4090），预测阶段实测 **15.00 秒**，包含 72 个案例的续算、四种缩放、投影评估、压缩保存与校验，不含解释器/模型构建和独立 CPU GT 评分。已有编译缓存、复用 C2 及几何缓存使其远低于预估预算。
- 两个后期步骤单次续算中位数约 **5 毫秒**；这不是完整重建或训练更新时间，不能外推 300 轮训练耗时。即使 scale=0 也计算梯度反馈，本实验不用于宣称加速。
- 没有新增剩余 draw：此次重点是固定布局下的步长机制，后续几何泛化仍需多布局独立验证。

## 后续决策

继续已经授权的小预算动态有界步长双臂实验，使用相同初始化、采样和训练预算作匹配控制。验收应同时关注普通与困难投影面板，冻结预测后再作验证三维评分；不能根据本次 GT 给每个案例或布局挑最优缩放。若困难组无实质收益，应转向 MRGR 的空间多尺度改进，而不是直接用本次极小收益启动新的 300 轮训练。
