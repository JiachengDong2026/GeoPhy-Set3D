# 多尺度 MRGR：非羽流圆环目标小测试

完成时间：2026-10-17T02:24:35.453052+08:00。使用已完成300轮训练、验证投影选出的第278轮冻结权重；单个新合成目标、单个普通V4布局。

最终三维相对L1为 **93.72%**，相对L2为 **85.25%**，Dice10为 **0.536**，Dice50为 **0.221**。

**结论：当前冻结模型在这个非羽流圆环上的泛化表现较差。** 重建仍集中在目标附近，但把中空圆环恢复成中心有较高浓度的团块；在共同50%阈值的三维图和三组正交切片中，原有中空结构未恢复。空洞区域的预测平均浓度达到GT峰值的54.80%，GT对应值仅0.47%。

反馈将三维L1从102.78%降至93.72%，质心偏移从30.53mm降至16.32mm，但空洞平均浓度反而升高，说明整体误差改善不代表形状正确。最终输入投影误差仍为42.37%，额外60站为49.20%；64³表示基线的对应投影误差只有约1%，无法解释如此大的重建偏差。本例连输入测量也未能充分拟合，不能把失败仅归结为未观测方向的不确定性。

## 目标与测量

目标为水平中空高斯圆环：中心(0.3,0.3,0.3)m，大半径0.12m，管截面标准差0.025m，解析峰值质量分数0.08；y为竖直方向。目标参数及布局在计算模型输出前保存，未根据结果调参。它是用于检验形状迁移的标量场，不是流体模拟的稳态解。

复用既有普通V4评价第一例的站位[4, 30, 47, 59]，方位角为[79.5, 118.41, 123.68, 49.03]°。没有新增聚簇困难条件。其余60站全部作为额外投影评价，未输入模型；它们是相关的几何观测，不是60个独立目标。

在128³端点网格生成解析场，通过原始独立CPU参考投影器（256采样点）生成ppm·m测量；模型输入沿用训练集固定归一化尺度。64³解析场只用于评分及表示误差基线。没有训练、测试期优化或读取已有数据集的三维标签/最终test。

输入最大测量/训练归一化尺度为0.848，GT64平均质量分数为0.00105（训练统计均值约0.00392）。
