# 多尺度 MRGR：相同非羽流圆环的分散六视角测试

完成时间：2026-10-17T02:29:11.955057+08:00。沿用上次圆环、全部测量、冻结第278轮权重和训练归一化，改变输入站位。

**分散六视角最终三维L1为76.13%，原四视角为93.72%，相对误差降低18.77%。** Dice50由0.221变为0.407。

**扩大覆盖后有改善，但当前模型仍未恢复圆环中空结构，而且六视角未优于本次分散四视角。** 普通V6三维L1为75.61%、Dice50为0.433；分散V4的L1为69.97%、Dice50为0.430。按L1计本次分散V4最低，按Dice50和质心偏移计普通V6较好，各指标存在取舍，不能给出全面最优布局。

从分散V4到其超集分散V6，三维L1由69.97%升到76.13%，增加6.16个百分点；共同未输入投影L1从37.17%升到41.74%。因此本例的改善不能简单归因于视角更多，更宽覆盖的四视角本身已提供明显收益。当前模型是学习得到的融合与反馈网络，并不保证输入观测增加后误差单调下降；此处没有机制对照来进一步确认原因。
