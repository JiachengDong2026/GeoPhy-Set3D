## 执行说明

首次预测读取保护拒绝对刚保存的预测 NPY 做哈希，未完成评分，也未读取 GT。保留失败记录于 evaluation/failed_prediction_guard_*；在独立测试入口中只额外允许本轮精确 180 个输出路径读取，保留训练保护代码不变，重新生成全部 180 份预测后完成评分。正式训练源码、冻结检查点和方案 B 训练均未修改。

**结果评估与使用判断（基于当前冻结结果）：** 方案 A 在常规观测条件下取得了可复核的小幅精度改善，且具有较快的单案例推理速度；作为自由视角方法，其困难几何鲁棒性仍未达到原设计目标。可以保留为常规覆盖下的候选模型，目前不适合全面替代历史 MRGR。

**常规四视角的改善有案例层面的支持。** 32/36 个案例改善，平均三维相对 L1 绝对下降 0.546 个百分点，相对下降 5.67%；案例配对 bootstrap 的 95% 区间为下降 0.256–0.824 个百分点。误差中位数从 8.450% 降至 8.341%，P90 从 15.742% 降至 14.310%，最差案例误差从 22.986% 降至 21.193%。平均与尾部均有改善，但典型案例的中位数收益较小。该统计仅针对本次案例、布局和训练种子，不等于跨种子稳定性，也不消除验证集参与检查点选择带来的局限。

**聚簇退化是主要问题，但应准确限定其条件。** 重放的 clustered-V4/draw0 四站方位跨度仅为 1.6907°，36 个案例使用同一站位组合；这是几乎同方向的极端有限角度观测，不代表所有“非均匀四视角”。该组误差中位数由 41.881% 升至 54.745%，P90 由 58.707% 升至 68.305%，28/36 个案例退化。平均误差增加的配对 95% 区间为 8.631–16.943 个百分点，表明问题并非由少数异常值造成。需用更多方位中心、跨度和布局确定退化边界，不能据单组推定所有聚簇条件均退化。

**投影拟合与空间重建仍有差距。** 常规四视角下三维 L2 为 16.06%，浓度体积分相对误差约 0.68%；聚簇组体积分误差约 4.00%，但三维 L1 达 56.75%，额外 H4 投影误差达 31.94%。这说明总量较接近也可能伴随明显空间分布错误，训练投影选择指标的改善不能直接替代三维评价。额外 H4 只用于本模型的诊断，不与历史模型作未经站位配对的比较。

**原因目前只能提出假设。** 狭窄角度下信息不足是两模型共同面对的困难，但不能单独解释 A 相对 MRGR 的退化。可能因素包括训练随机采样很少覆盖此类极窄布局、显式更新/预条件在欠观测方向上的行为，以及学习先验对这些方向的约束不足。需要同初始化的逐步物理能量、留出误差、更新幅度和裁剪比例诊断，以及匹配的迭代数/预条件/先验消融才能区分。当前预算版同时改变了结构和执行精度，缺少原始 A 的匹配精度结果，不能将退化归因于加速、BF16 或某个特定模块。

**后续优先级：** 先补齐历史剩余四组 V3/V6/聚簇 draw 的冻结模型评价，并按实际角度跨度分层；随后在保持检查点不变的前提下分析 A 的四步更新与 MRGR 对应失败案例。若确认极窄几何存在过大更新或裁剪，再以独立协议做单因素改动，检查普通几何是否受损。几何增强需使用单独的匹配对照；当前验证 GT 已用于开发判断，不能再将其作为后续改进的独立盲测证据。跨种子、噪声/标定误差及最终测试用于后续确认，而非靠延长当前已接近平台的训练来替代。

**对原研究假设的判断：** 当前结果支持“在若干常规几何下改善三维重建”；原先“显式梯度和预条件能降低困难几何误差、同时控制普通几何退化”的假设尚未得到支持，在本轮极窄聚簇组上出现了相反证据。论文和模型说明应明确保留这一失败条件。

**参数增加但收益有限：进一步原因分析。** 源码构建复核得到历史 MRGR 332,070 参数、当前预算版 A2 488,919 参数，增加 47.23%。A2 初始化器为 306,625 参数，多尺度先验为 182,274 参数，四步嵌入和步长合计 20 参数；四步共用先验，参数量不乘四。历史模型的视角交互与融合合计只有 12,933 参数，残差编码与适配合计 12,512 参数。新增参数主要用于三维卷积，而非增加观测信息或恢复历史的视角关系建模。参数和第 299 轮诊断汇总保存在 `evaluation/frozen_model_test/architecture_cause_diagnostics.json`。

首先，当前比较包含了“删除已有几何机制”和“增加展开机制”两个因素。历史 MRGR 使用 OARI 的视角关系/局部方向多样性描述及几何条件融合，再作残差特征反馈；当前 A2 使用 DeepSets 可见性加和除以四作为初始化，再作四步精确梯度与共享先验更新。A2 仍有几何 lifting、物理算子和覆盖特征，不能称其没有几何信息；但它没有历史网络显式的跨视角关系与方向多样性描述。新机制的收益可能部分用于弥补初始化器变化，净提升小不等于新机制独立无效。反过来，也不能把全部 5.67% 净收益归功于精确梯度，因为尚无同容量、同初始化的完整训练控制。

其次，精确梯度主要降低输入测量误差，不会自动补足欠观测方向的信息。内部更新的目标是输入射线归一化平方误差，外部训练则含 SmoothL1、相对 L1、cross/hold 和体场一致性；内部方向并非整个外部目标或三维 GT 误差的精确下降方向。在极窄角度下，很多不同空间分布可以产生近似测量，额外迭代可能提高拟合，却未必提高真实空间精度。几何预条件改善数值尺度，也不等于解决方向不可辨识性。

第三，现有迭代日志揭示了值得优先检查的先验与约束行为。最佳第 299 轮固定测量验证包含 36 案例的 A/B 两分支，共 72 次重建；每步开始处的输入平方残差能量均值依次约为 1.237e-2、7.375e-5、3.002e-5、1.791e-5，说明整个更新链条确实在降低输入残差，但无法从这些数值分离物理步和先验各自贡献。先验后的越界裁剪比例约为 85.2%、89.4%、89.2%、89.3%；第三、四步实际物理变化范数均值约为 0.032、0.025。这提示应检查背景抑制、前景边界恢复以及后续步骤的边际收益。由于场稀疏，大量背景归零可能是合理行为；先验范数在最终裁剪前统计，不能用其较大范数直接断言先验主导有效更新，也不能将全网格裁剪比例当成前景梯度失效比例。

第四，预算版的参数量不能代表其空间表达方式与原始 A 完全一致。当前先验主体在 32³ 上执行，再上采样；64³ 局部分支仅一层 3×3×3 空间卷积加输出头，最终浓度场仍为 64³。它保留了可学习容量，却改变了高分辨率空间处理与频率响应；是否影响细节或狭窄几何下的消歧需要匹配控制。128³ 源场/高采样投影与 64³/Q96 模型也有已知离散差异，但该差异是两模型共同背景，不能单独解释 A 的相对退化，更不能据此认定三维 L1 已到精度下限。

第五，没有充分证据把结果归结为简单的“参数多导致过拟合”或“还没训够”。第 299 轮训练和验证的留出投影相对 L1 分别约为 2.408% 和 2.724%，未出现很大的投影泛化差距；不同采样条件也使二者不能作为严格过拟合检验。现有接近平台的验证曲线不支持仅靠增加轮数就解决极窄几何退化。四步共享先验、各步全局标量步长、按输入平方误差更新以及未针对极窄几何分层训练，都是比继续堆参数更值得先核查的限制，但尚无消融结果证明其中哪项为主因。

**对改进有效性的审慎结论：** 当前完整 A2 模型对常规布局有小幅收益，但单位参数和训练成本对应的收益有限，困难几何上的核心主张尚未成立；精确梯度、预条件和先验的独立必要性仍未知。最有信息价值的后续实验依次是：冻结同一检查点保存 C0→C1→C4 及物理步前后状态，分别观察输入/H/三维误差；用同初始化、同容量、同训练预算的学习反馈控制检验精确梯度；单独恢复方向多样性描述或 OARI 初始化，区分几何信息和更新规则的作用。中间状态仅是同一联合训练模型的诊断，不能替代从头训练的消融。以上为后续建议，本轮没有修改模型、追加训练或宣称因果验证完成。

**后续实验已完成：** 用户随后授权的小预算试验见[三项机制实验报告](plan_a_mechanism_experiments_zh.md)。已完成 72 次冻结模型轨迹重放及三组各 20 轮/160 更新的独立训练，训练合计约 4 分 46 秒。后期物理步存在“输入投影误差下降但三维误差上升”的明确轨迹证据，学习先验随后补偿；同时当前 A2 的短程最佳验证投影 L1 为 17.04%，优于同参数学习反馈控制的 21.22%，表明不能简单断言物理更新无效。恢复 OARI 初始化的短程最佳值为 17.63%，尚无追加长训练的积极证据。短程对照未读取 GT，不能据此推断完整 300 轮的三维精度或困难几何排名。
