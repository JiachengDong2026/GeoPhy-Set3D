# 资源最省的下一步建议（不执行）

优先复用已经完成的 **Uniform Fusion** `uniform_no_ray_relations_seed20261011`，暂不增加训练。
该任务已在 `docs/reports/mrgr_uniform_ablations_v1_zh.md` 登记完成；只有单种子，不能称双种子证据。
当前正式主模型也为 Uniform Fusion，使用已核验的 seed20261011 正式权重。
任何后续运行仍需重新核验消融 checkpoint/config SHA 和封存清单，不能混入 GCA 分支。

当前竞争解释是：聚簇中显式关系的即时 attention 响应小，但可观测性 token/残差路径仍可能重要；
训练移除关系后的性能差异还包含参数适应，不能直接等同于正式模型的即时关系贡献。

建议仅对预先固定案例索引0、17、34，在普通V4与clustered-V4的draw0做现有无射线模型的
`A0` 与 `obs_token` 冻结探针。主模型相同输入的本轮全部结果直接复用；无射线模型既有A0预测也应复用，
只补缺失的OARI中间量与6份obs_token新增输出。先检查这6个输入能否显示 token路径依赖的变化，
无需无差别扩大案例、增加新布局或重新读取GT。

还可先做CPU代数检查：无射线模型的 `MaskedPairBias` 把前三关系输入置零，
同一体素的每个有效pair因此接收相同的可观测性输入。即使MLP含非线性，
此时对所有有效key的bias仍是共同常数，理论上会在softmax抵消（浮点实现需按容差核验）。
这与完整模型中“关系与obs共同进入非线性MLP”不同；后者的obs变化可产生key差异。
该代数性质不需要GPU，也不需要读取另一个训练检查点。

若无射线模型的token路径敏感性与正式模型不同，这与训练后依赖重分配一致；
不能据此唯一证明训练性能差异的补偿机制。若仍需因果识别重训练贡献，再围绕一个明确的竞争假设预登记最小配对训练，
而非重复已完成的整OARI、无射线关系或GeometryLifting消融。

本文件仅为后续建议。本轮没有加载该消融模型、没有新增这些推理、没有训练，也没有GT访问。
