# OARI三项机制诊断：结果解读

本页解释[已验收报告](mrgr_oari_mechanism_diagnostics_v1_zh.md)，不改变封存统计，不新增推理、评分或训练。

关系偏置不能概括为“训练后几乎没学起来”。在固定3例、五类布局draw0的采样中，bias RMS约为内容logits的6%–27%；虽然幅度较小，普通V4、spread-V4、V3、V6的去偏置attention JS分别约为0.0673、0.0989、0.0567、0.0896。偏置实际改变注意力，幅度比本身不能判定其无效。

clustered-V4明显不同：去偏置attention JS约0.0000536，P1关系错配JS约0.0000110；key中心化bias RMS约0.0213，其他四布局约1.01–1.38。该采样更符合“聚簇条件下显式关系对候选视角的区分作用较小”，不能据此推断全部35例或整个OARI无效。OARI还包含几何与可观测性嵌入、内容交互和残差路径。

普通V4的P1/P2错配或去贡献也改变attention，JS分别约0.0408、0.0673；但attention改变不等于重建收益。历史全部35例的L1差异从C0到C1缩小，P1平均衰减0.331944个百分点，P2衰减0.720634个百分点。这里是最终指标变化被后续精化削弱，不能证明物理反馈是唯一补偿来源；Dice、L2和质心指标需分别解释。

现有证据不支持仅凭“偏置太弱”增强或重做OARI。更需要谨慎考虑布局条件性、其他几何信息的冗余和后续补偿，但本轮不能区分这些解释，也不能裁定应删除整个OARI。已有训练消融在普通V4区间跨零、聚簇布局退化较大，与冻结聚簇干预的小幅改善必须同时保留。

B完全复用已有指标，无重新推理或GT读取。A/C完成45次有效采样；首次数值复核在12次前向后因SciPy近零JS舍入问题停止，输出及错误保留。恢复单独登记，总前向为57次，未修改模型、干预、案例或统计方案。所有57份输出再次核对历史预测，未读取GT64/GT128。详见[验收](artifacts/mrgr_oari_mechanism_diagnostics_v1/acceptance.json)与[恢复登记](artifacts/mrgr_oari_mechanism_diagnostics_v1/numerical_recovery_v1.json)。

GeometryLifting重新训练消融仍独立运行，原GPU分配、进程、batch和协议不变。本轮OARI结果不用于调整该训练或选轮。
