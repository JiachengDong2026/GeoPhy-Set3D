# 假设 t=2 s 已达稳态：羽流条件与训练集定量分析

日期：2026-10-16。本文接受用户给定的**瞬时场已近似稳态**前提，讨论由此前提导出的物理条件，并实际分析现有训练集浓度。它与[先前稳态证据核查](dataset_t2_steadiness_audit_zh.md)回答不同问题：先前核查仍为“现有时序证据不足”；本文不重新判断是否达到稳态。

## 1. 稳态意味着持续输运下的平衡

对同一固定工况，若浓度、密度和流场均已稳定，则在相关时间尺度上：

\[
\partial_t C\simeq0,\qquad \partial_t\rho\simeq0,\qquad
\partial_t\mathbf u\simeq0.
\]

因此 \(\partial_t(\rho C)\simeq0\)。气体仍可持续喷出、上升、被横风输送、混合并离开重建域；空间形态近似固定。这里假定源、来流及其他边界条件也稳定。如果仅为统计稳态，单帧不一定满足这些条件，须改用一致的平均方程与湍流通量闭合。RANS 情形中密度加权平均量与普通平均量也不可任意混用。

### 1.1 局部：对流、扩散与源项平衡

对于质量分数 C，采用与 CFD 一致的有效扩散闭合：

\[
\mathbf J_C=\rho\mathbf uC-\rho D_{\rm eff}\nabla C,
\qquad \nabla\cdot\mathbf J_C=S_C.
\]

\(\mathbf J_C\) 为甲烷质量通量，单位 kg·m⁻²·s⁻¹；\(S_C\) 为体积质量源，单位 kg·m⁻³·s⁻¹。在源区之外 \(S_C=0\)，但对流项与扩散项通常各自非零，只有两者的散度相平衡。稳态本身不能推出 \(\nabla^2 C=0\)。如果泄漏由边界注入表示，同一泄漏不应再重复记为体源。

流场还需满足相应连续性与动量平衡。在无体积质量源区域，\(\nabla\cdot(\rho\mathbf u)=0\)。历史设置有重力、混合物密度差异与 SST k–ω；因此 \(\mathbf u\) 一般包含喷流、浮力和局部流动，不能仅用 metadata 的环境风速替代。若采用梯度扩散模型，常见表达为 \(D_{\rm eff}=D_m+\mu_t/(\rho Sc_t)\)，实际仍需以 Fluent 设置为准。

### 1.2 全域：输入与输出通量相等，无净积累

对当前重建盒 \(\Omega=[0,0.6]^3\,\mathrm m^3\)，外法向为 n：

\[
\underbrace{\frac{d}{dt}\int_\Omega\rho C\,dV}_{\simeq0}
=-\oint_{\partial\Omega}\mathbf J_C\cdot\mathbf n\,dA
+\int_\Omega S_C\,dV.
\]

即稳态时：**甲烷净向外通量 = 域内体源供给**。如果所有泄漏均通过边界进入、且无体源，则整个边界的带符号净通量为零，等价于总输入与总输出相等。允许从侧面、顶部或其他实际开放面离开；需要考虑对流和扩散两种通量。

同一工况的真实质量 \(\int\rho C\,dV\) 随时间稳定，但不同风速、源强和布局的稳态质量可以不同。无密度时可计算的 \(\int C\,dV\) 单位是 m³，不能当作 kg，也不能要求所有案例取同一个值。

### 1.3 分层：守恒的是通量，不是每层的浓度积分

设水平截面上的向上总甲烷通量为：

\[
F_y(y)=\int_{A(y)}\left(\rho u_y C-\rho D_{\rm eff}\partial_y C\right)\,dx\,dz.
\]

对 y₁ 到 y₂ 间的控制体：

\[
F_y(y_2)-F_y(y_1)+F_{\rm lateral}=\int_{\Omega_{12}}S_C\,dV.
\]

只有层间无源、侧向净通量可忽略时，才有 \(F_y(y_2)\simeq F_y(y_1)\)。即使如此，\(I(y)=\int C(x,y,z)\,dx\,dz\) 也不必恒定，因为速度和密度可以变化。随高度增大，羽流可以展宽、偏转、合并；固定坐标点的浓度不必单调减小。

### 1.4 浓度范围及有条件的最大值原理

质量分数应满足 \(0\le C\le1\)，并满足源口、来流、壁面和开放边界的实际条件。对平滑、源外、无反应且有效扩散严格为正的稳态标量方程，在质量连续性成立时，强最大值原理排除无支撑的严格内部局部极大值；可把远离源和边界的孤立尖峰列为核查对象。

这不等于要求整个羽流单峰、每个二维切片无峰、只有一个连通块或呈高斯形。多源、复杂边界及插值误差必须单独处理；不能据一张切片上的亮点或空洞直接判断违反 PDE。

## 2. 本次实际读取的数据与计算口径

- 只打开 **166 个 train 案例**的原始 C128 与派生 GT64；未打开 val/test 数组、投影数组或模型权重。

- 每份 C128 在加载前核对 source index 中的 SHA-256，另保存全部数组读取清单和 GT64 哈希。
- 下文 1% 表示 **C≥0.01 的甲烷质量分数**，仅为固定空间描述阈值，不是摩尔分数、爆炸阈值或稳态判据。

## 3. 训练集支持的具体发现

### 3.1 羽流经常到达盒子边界，边界处理决定守恒约束是否正确

下表表示各面至少有一个 C128 节点达到 C≥0.01 的案例数，不是通量值：

| 来流风速 m/s | 案例数 | 顶面 y=0.6 m | 侧面 x=0.6 m |
|---:|---:|---:|---:|
| 0 | 49 | 49 | 1 |
| 1 | 48 | 32 | 48 |
| 2 | 21 | 8 | 21 |
| 3 | 48 | 2 | 48 |
| 总计 | 166 | 91 | 118 |

所有案例底面均达到该阈值。其余 x=0、z=0、z=0.6 三面分别有 1、11、20 个案例达到阈值。

这说明不能把所有外边界强制设为 C=0，也不能要求羽流在盒内形成完全封闭的等值面。无风组的顶部浓度和有风组的 x=0.6 m 面浓度尤其需要保留。实际外流方向及通量大小仍须由速度与边界定义核实；仅凭浓度不能认定该面是 CFD 的正式出口。

### 3.2 无风与有风的空间分布差异明显

定义浓度权重高度质心 \(y_C=\int yC\,dV/\int C\,dV\)，以及顶面截面比 \(r_{\rm top}=I(0.6)/(\int C\,dV/0.6)\)。两者均是浓度描述量，前者不是密度加权质量质心，后者不是顶面流量占比。

| 来流风速 m/s | y_C 中位数 m | ∫C dV 中位数 m³ | r_top 中位数 |
|---:|---:|---:|---:|
| 0 | 0.3972 | 1.0106×10⁻³ | 1.8795 |
| 1 | 0.3680 | 1.0861×10⁻³ | 1.0672 |
| 2 | 0.2664 | 7.7890×10⁻⁴ | 4.96×10⁻¹⁷ |
| 3 | 0.1701 | 4.5767×10⁻⁴ | 4.96×10⁻²¹ |

无风组顶部的截面浓度积分高于沿高度平均值，是允许的稳态空间分布。较强来流组的浓度权重高度更低、顶部贡献更小，同时侧面仍有显著浓度，符合横向输运影响增强的解释。

但这是**未匹配工况的描述统计**，压力、孔数和布局组成不同，source_mode 元数据全部为空。因此不能把表中变化全归因于风速，也不能由 0→1 m/s 的体积分上升推出违反物理。各工况不应共享同一羽流形状、质心高度或总量硬约束。

### 3.3 近源峰值的离散损失远大于全局积分变化

| C128→GT64 描述量 | 本次训练集结果 |
|---|---:|
| C128 全局峰值 | 全部约为 1；最小为 0.9999994 |
| GT64/C128 峰值比中位数 | 0.63337 |
| GT64/C128 峰值比范围 | 0.42985–0.73249 |
| ∫C dV 相对变化中位数 | −0.02435% |
| ∫C dV 相对变化范围 | −0.14494% 至 +0.06375% |
| 高度质心变化范围 | −0.10194 至 +0.15000 mm |

全部案例的底面最大值与全局峰值在 10⁻⁶ 内相同。C128 近纯甲烷峰集中在底面，与源口边界高浓度的解释相容；具体源口坐标和面通量仍须由几何与 CFD 定义确认。

由此得到两点直接结论：

1. **总量和质心几乎不变，可以同时伴随很大的峰值下降。** 因而仅改善全局 L1、浓度体积分或质心不足以证明恢复了近源结构。
2. 对输出 C64 的模型，预测低于 GT64 才能计入相应的模型峰值误差；GT64 相对 C128 已损失的峰必须单独列出。该重采样结果不是所有 64³ 反演方法的绝对性能下界，但不能把它全部算成网络造成的损失。也不应在任意 C64 底面节点强行要求 C=1，因为节点未必命中原始源口峰。

## 4. 对后续重建分析的建议

**现在可以完成的比较：** 在同一 C64 节点及相同积分权重下，逐模型、逐案例比较浓度体积分、浓度权重质心、分层 I(y)、六面浓度和源附近峰；按风速、孔数及布局分层。它们可以揭示“峰变低但总量不变”“羽流被搬到错误高度”“边界被错误截断”等差异，但应标为形态诊断，不能称为输运残差。本文只计算了数据集基线，未新增三模型评分。

**真正的稳态物理约束：** 恢复同工况的局部 u、ρ、有效扩散及源/边界数据后，优先在源外及分层控制体上计算：

\[
R_K=\oint_{\partial K}\mathbf J_C\cdot\mathbf n\,dA
-\int_K S_C\,dV.
\]

先计算 GT 在同样离散与映射下的残差基线，再比较预测；同时核查全域输入—输出通量。控制体残差应按质量流量尺度归一化，源口与开放边界须显式处理。只有确认背景速度可以近似冻结，才把输运作为已知系数标量方程；近源 C≈1 提示不应未经验证就把整个场当作稀释被动标量。

若随后做训练对照，可用现有测量目标加小权重的稳态控制体残差，评价是否改善峰位、分层结构和独立视角投影。使用训练 GT 拟合形态先验或提供 CFD 流场属于新增信息协议，应独立登记。稳态假设并不保证少视角重建唯一，也不支持直接追加全域 Laplacian、全边界零浓度或随高度单调等硬约束。
