# A 有界动态步长匹配短程筛查

本实验不是正式 300 轮训练，也不构成三维精度结论。全程仅使用投影，未读取体素 GT。

两臂的共有参数从完全相同随机权重开始，动态臂额外增加两个零初始化标量。使用全部 166 个训练案例、36 个验证案例、相同视角采样与 shuffle，以及 300 轮 cosine 的相同前缀；每轮 83 次更新。未缩短 cosine 到 16 轮。

唯一干预为后两步物理位移的有界动态强度：`rho=detach(||clamp(C−tau*U,0,1)−C||/(0.25||C||+1e−8))`，`gamma=2*sigmoid(−a_k*rho)`，`Z=clamp(C−gamma*tau*U,0,1)`。保留物理校正与可学习强度梯度、原 prior_signal，rho 统计量不反传，gamma 在 FP32 计算，前两步不变。两个新增标量零初始化，因此初始 gamma 精确为 1，继承 reference 的前向与共有参数梯度；学习时 gamma 在 (0,2) 内，可衰减或增强。0.25 是预注册固定值，未搜索。每轮 metrics 含 gamma/rho 分布与 a_k。

| Arm | Epochs | Updates | Best H | Final H | Runtime | Parameters |
|---|---:|---:|---:|---:|---:|---:|
| reference | 16 | 1328 | 8.1380% | 8.2858% | 7.06 min | 488919 |
| bounded_dynamic | 16 | 1328 | 8.3774% | 8.3774% | 7.29 min | 488921 |

动态臂相对 reference 的最佳 H 变化为 +2.94%，末轮 H 变化为 +1.11%。最佳 reference 出现在第 15 轮，动态臂最佳出现在第 16 轮。这只反映短程投影泛化，尚不能证明普通/困难布局的三维收益。两臂训练入口合计约 14.35 分钟；包括 Python 进程启动退出的合计记录约 14.45 分钟。

已核对：共有参数初始化哈希相同、视角采样 manifest 相同、最终 loader RNG 与 scheduler 相同、梯度有限、全部冻结 src 文件哈希不变、两臂 GT 读取次数及禁止读取尝试均为 0。由于新增两个参数，两臂完整 state_dict 哈希不同。初始前向最大差为 2.384×10⁻⁷，通过 10⁻⁶ 容差检查，并非逐位相同。两臂均未产生正式 freeze.json。

实际动态幅度很小，是解释本轮结果的关键限制。末轮固定验证布局的控制量如下（每步 72 个 A/B 分支记录）：

| Step | a_k | rho mean | gamma mean | gamma P10 / P90 | gamma min / max |
|---|---:|---:|---:|---:|---:|
| 3 | −0.00466819 | 0.0438597 | 1.0001024 | 1.0000620 / 1.0001531 | 1.0000471 / 1.0002503 |
| 4 | −0.00329215 | 0.0326472 | 1.0000538 | 1.0000321 / 1.0000861 | 1.0000261 / 1.0001270 |

也就是说，末轮平均步长只增强约 0.0102% / 0.0054%，没有学到有意义的后期减步。全部 16 轮验证中最大的 `|gamma−1|` 也只有 0.0007066。此处尚不能把结果泛化为“动态控制机制无效”；当前零初始化、统计量尺度和优化设置组合只产生了非常弱的控制。

随后按主 agent 要求追加独立、事后标记的纯测量反事实检查：在同一末轮动态 checkpoint 上，分别使用正常 gate、将 a_k 置零（gamma 恒为 1）、恢复正常 gate 重复。三次均为固定 36 个验证案例，仅改变内存中的 a_k，不训练、不读 GT、不修改 checkpoint。

| 同 checkpoint 推理设置 | H |
|---|---:|
| 正常 gate | 8.377296803% |
| gamma 恒为 1 | 8.377385086% |
| 恢复正常 gate 重复 | 8.377295996% |

去掉 gate 的 H 变化仅为 +0.0000883 个百分点（相对 +0.001054%）；正常重复差为 −0.000000806 个百分点。直接推理作用远小于两臂短程 H 差。该结果不能消除训练中的共同适应，也不能把两臂差全部归因于 CUDA 数值波动；本轮未做 reference 重复训练，未估计训练重复方差。

独立补测进程的正常 gate 重放与训练日志末验证还相差约 −0.0001166 个百分点；因此这里只比较同一补测进程内的三种设置，不把跨进程末位差当作模型改进。

补测耗时约 17.58 秒，checkpoint SHA256 前后一致，GT 与禁止读取尝试均为 0。事后脚本为 `scripts/probe_a_dynamic_gate_counterfactual_v1.py`，产物位于 `outputs/research/a_dynamic_steps_v1/posthoc_gate_counterfactual/`；汇总解释为 `postrun_analysis.json`。已注册的原训练脚本未修改，本报告对“共有参数哈希”的措辞在结果生成后修正。

结论：当前这个有界动态步长版本没有积极筛查收益，不晋级到正式 300 轮训练，不继续为其追加训练。该结论限定于此初始化和优化设置，不能据此否定具有实际调制幅度的动态物理校正。下一步优先综合冻结缩放诊断及同期 MRGR 多尺度候选。

局限：单种子、早期学习阶段；投影 H 并非三维误差；未进行 GT 评估或独立最终测试；未通过困难几何专门训练验证；尚无多种子重复结果。
