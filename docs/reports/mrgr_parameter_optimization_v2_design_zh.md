# 多尺度 MRGR 参数优化 v2：预注册设计

本轮负责两种相互独立的单变量优化。主模型保持已有多尺度 MRGR（344,678 参数），与本轮新训练控制在 GPU2 串行比较；不会复用历史不同 GPU 的控制作为因果参照。

| 路线 | 唯一改变 | 机制动机 | 主要风险 |
|---|---|---|---|
| control | 原配置 | 建立同环境新控制 | GPU 数值轨迹仍可能漂移 |
| lr4e4 | AdamW 初始学习率 2e-4 → 4e-4 | 检验短前缀是否受优化速度限制 | 更快早期下降不代表最终收敛更好，可能损害稳定性 |
| consistency001 | A/B 三维场一致性权重 0.05 → 0.01 | 检验一致性项是否压制局部细节并与测量拟合竞争 | 投影收益未必改善三维；跨视角一致性可能下降 |

每个种子内部的所有组均从相同新初始化开始，166 训练 / 36 验证，batch 2，FP32，AdamW weight decay 1e-4、梯度裁剪 1，沿用 300 轮余弦调度的前 20 轮。主种子 20261018；所有通过固定门槛的候选再与新控制做种子 20261019 的匹配复核。绝不以最佳轮替换固定 epoch20 的筛查终点。

筛查门槛沿用既定标准：普通 H 留出投影相对 L1 均值至少降低 1%；普通病例 P90 与聚簇五布局均值恶化不超过 2%；每轮耗时增加不超过 20%；300 轮外推不超过 5 小时；正确性、输出非退化与无 GT 访问审计通过。bootstrap 以 36 个配对病例为单位，聚簇的五次布局先在病例内平均。病例置信区间不包含训练重复不确定性。

## 机制证据

原一致性项为 `mean(|C_A-C_B|) / (0.5 * (mean(|C_A|)+mean(|C_B|)) + 1e-6)`，并非扩散方程约束。它鼓励两组输入得到相近的场，但二者共同的投影零空间错误仍可能保留。

历史多尺度 300 轮日志中，加权一致性项占训练总损失的比例从第 1 轮的 0.42% 上升至第 20 轮的 23.40%，第 300 轮达 29.06%。这个损失占比支持单独测试权重，但不证明一致性项有害，也不等于梯度贡献。该观察在候选结果产生前保存在 `historical_loss_mechanism.json`。

本轮初始固定前两训练案例的真实全参数探针中，一致性项梯度范数仅为原总梯度的 0.0794%，与原总梯度余弦约 -0.179。初始测量损失很大，故该结果不能替代末期探针。每个候选完成第 20 轮后，固定使用同样的两训练例复算分量与梯度；只读评估，不更新训练权重。

## 完整记录与边界

每轮记录实际训练目标、原标准目标 `standard_total`、全部原始 loss 分量、实际加权一致性项、H 误差、最大裁剪前梯度、学习率、站位与 loader RNG 哈希、时间和峰值显存。每组最终权重、优化器、调度器与 RNG 状态落盘；普通 36 例及聚簇 180 条病例记录保留。

训练和筛查仅读取 Pool A train/val 投影。H 不输入重建网络。三维 GT 与最终 35 例测试集不进入本轮筛查；正式 300 轮及冻结三维测试由主 agent 综合多路线结果决定。

产物目录：`outputs/research/mrgr_parameter_optimization_v2/`。数字 runner 为 `scripts/mrgr_parameter_optimization_v2.py`，独立 CPU 验证为 `scripts/verify_mrgr_parameter_optimization_v2.py`。协议、数据及源文件运行前封存，发现改变则停止。

补充：`training.seed` 同时控制初始化和站位采样，所以普通验证 A/B/H 布局在两种子间改变；同一种子的各组站位严格配对。聚簇五布局使用同一历史预注册站位，与种子无关。第二种子可解释为新初始化和新普通布局的匹配复核，不能当作只改变初始化的重复实验，也不把两次36例拼成72个独立病例。
