# 固定案例体素优化与网络拟合诊断 v1

本轮只诊断已有自监督基线的失败机制；不启动正式300轮，不读取真实三维GT、Pool B或最终test，不改变冻结模型和历史结论。

固定train索引0、82，seed20261011、epoch0原A/B/H、完整64³与全部有效K96射线。训练目标直接调用原objective。H仍是原训练目标的一部分，不能称为本轮独立评价；E取不在A/B/H中的最小四个站位ID，仅在0/10/50/100/200步作评价，不进入目标或网络输入，不用于选模。

每案例三个预定臂：

- voxel_sigmoid：共享案例专属体素logits；A/B返回同一sigmoid场。AdamW lr2e-4/wd1e-4。
- voxel_scaled：共享案例专属c0*u场，每步投影到浓度[0,1]；AdamW lr0.05/wd1e-4。此臂故意改变优化尺度，检验存在性和条件数，不能作严格等优化器架构排名。
- unet：原始五层U-Net，复用冻结c0/alpha、同seed fresh初始化；AdamW lr2e-4/wd1e-4。每案例独立fresh，不能继承其他臂。

两个直接场都从fresh U-Net A/B输出均值开始；U-Net保留原A/B各自初态，差异如实报告。原梯度裁剪1；cosine T_max300每16次更新推进一次，与原pilot更新尺度一致。FP32、batch1单案例诊断，全部CPU双线程串行；此处不冒充原batch2/多案例正式训练。

每臂恰好200更新，共1200上限。预检无优化器更新。每步持久化真实参数变化及计数；0/10/50/100/200保存指标及包含optimizer/scheduler/RNG的checkpoint，最终checkpoint与初末完整场封存。异常立即保存真实步数，检查后报告，不重放或通过重启掩盖失败。不根据中间结果改变loss、学习率、预算或E选择。

诊断操作判据：最终A/B/H relative L1各≤0.9且总loss较初态下降，记为非平凡测量拟合；E≤0.99单独报告。未通过只说明本参数化和预算下未成功，不证明无解；通过也不证明三维恢复正确，不授权正式训练。所有臂只用末态，不挑中间最佳点。

输出健康、初末完整场、原/独立NumPy积分、逐步更新和保护哈希一并报告。直接共享场不需要从测量推理，也没有A/B一致性难题，故它与网络的差异同时包含参数化、共享条件映射和一致性作用；不能仅以两者差距唯一归因架构。
