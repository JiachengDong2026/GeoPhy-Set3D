# 研究规划

目标：结合观测数据与物理约束，重建三维气体羽流。

以下内容尚待确定，避免在数据与物理假设明确前固定模型结构。

## 观测与数据

- 观测方式：相机、光谱、层析投影、传感器或其他输入。
- 数据形态：静态或时间序列，视角数、标定参数、采样频率。
- 数据来源：实验、仿真或公开数据；真实三维场是否可用。

## 重建目标与空间定义

- 待重建物理量，例如气体浓度或密度；明确定义与单位。
- 三维坐标系、重建范围、空间分辨率与时间分辨率。
- 观测量与三维物理场之间的前向关系。

## 物理约束

- 适用的控制方程、假设及适用条件。
- 已知或待估计的速度场、扩散系数和源项。
- 初始条件、边界条件及物理量约束。
- 物理残差的计算方式、单位和损失尺度。

## 算法与评估

- 先建立可验证的基线，再选择重建方法和模型结构。
- 明确数据一致性、物理一致性和三维重建质量的评估方法。
- 保存每次实验的配置、数据版本、随机种子和 Git 提交版本。
- 比较物理约束的消融实验与噪声、稀疏观测条件下的表现。
