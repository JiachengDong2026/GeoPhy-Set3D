# GeoPhy-Set3D 研究定义与评价框架修订 v1

日期：2026-10-13。本修订适用于冻结 Projection Pool v1、静态末帧 CH4 三维质量分数重建，以及冻结 SelfSup-MRGR v1 / 监督 MRGR 的方法比较。`GeoPhy_Set3D_v0.5_Technical_Plan.md` 与 `project-plan.md` 原样保留为历史计划；不重新生成 CFD、Projection Pool，不修改既有训练、checkpoint 或历史判据。RVTC v2 NO-GO、匹配 Control/Treatment 的不利 Val 结果继续有效。

## 1. 自由稀疏视角的有限定义

在明确的物理采集范围内，输入站位数量、顺序和空间组合可变，同一网络无需针对每种布局重新训练；性能随几何信息条件变化，不承诺任意布局具有相同精度或唯一恢复。

三个层面分别报告：

1. **物理可实现范围**：本数据 family 为目标中心 (0.3,0.3,0.3)m、半环方位 0–180°、半径 5.5–6.5m、站位高度 0.25–0.35m、水平扇扫 ±5°、垂直 ±4°。重建域为 XYZ `[0,0.6]³ m³`。使用冻结实际射线 origin、direction、near、path length、valid mask。其可实现性假设是光路无遮挡、标定已知，羽流在顺序扫描期间静态，或多站同步取得同一时刻信号；运动、遮挡、未知光路不在本次实测范围。
2. **几何信息条件**：域覆盖、三维射线方向互补和冗余。原中心方向分数、实际射线方向张量及采样方向分数只是描述，不是严格可观测性、条件数、唯一性证明。
3. **方法能力**：给定相同站位和测量，方法能够利用现有信息的程度。标签、数据驱动先验、优化预算、前向离散化和数值收敛分别解释。

极端 clustered 始终保留为退化压力测试。全部困难 case/draw 均进入统计，不要求其达到普通布局精度，不把该要求作为所有改进的硬门槛。

## 2. 重建方法与选站策略分开

重建比较固定输入测量、站位、有效射线和共同 H。经典算法与网络比较只能在同一 Original、Targeted 或 Random 条件内进行。GT 辅助调参、测量域调参、自监督网络、监督网络分别标注标签条件。

选站比较固定模型及 V4 预算，分别比较 Original→Targeted、Original→Random 和 Random→Targeted。几何改变带来的收益不能被表述为网络结构能力的增长，更不能只给本方法更好的输入后宣称网络优越。

## 3. 几何分层评价基础设施

独立入口 `scripts/register_geometry_catalog.py`，配置 `configs/evaluate_geometry_strata_v1.yaml`，只读取 Pool A geometry 与 source index 元数据，不读测量或 GT。覆盖描述在 endpoint-aligned 16³ 诊断网格上，用真实路径 K96 中点及非零三线性权重统计被至少一个/两个站位触达的节点比例，并保存三轴逐平面覆盖。它是采样触达 proxy，不等同连续光路覆盖或矩阵秩。

记录 V、保留输入顺序的 station IDs、XYZ origins、高度、到域中心距离、有效射线数、原中心方向分数、全部有效真实三维射线 Q 的特征值，以及最多512条等间隔实际射线的方向分数。实际射线采样分数受采样影响，Q 使用全部有效射线。

每个 V=3/4/6，先用固定 seed2026101301 生成256个无放回站位组合，按原中心方向分数的几何分布三分位冻结 low/middle/high 边界，平界归右侧。边界不读取 GT、网络或重建误差。自然随机评价保留历史 seed/identity 的36 Val×5draw；受控分层使用预生成组合；极端 clustered 保留原采样器的5draw。本轮完成清单、边界及哈希登记，**不运行整个 V3/V6/分层评价矩阵**。低方向分数的名称不意味着低 GT 准确性，更不自动证明不可恢复。

## 4. 第一轮优先实测协议

复用 clustered 单站位诊断的原36 Val case、5draw、Original/Targeted/Random IDs 和共同 H4。核对两个冻结网络 checkpoint、历史来源及逐条 station IDs 后，复用完整历史指标。网络速度单独实际前向计时，不重训。经典算法真实重建；H4 和待评 case 的 GT64 只能在重建输出落盘后读取。

校准仅使用 source-index train 顺序的12个等间隔 case，每例普通随机 V4 与固定困难 clustered V4，共24个 case/layout。每算法3个有界候选，全局配置分别按 train 体积 relative L1（GT 辅助）与独立 train H4 relative L1（测量选择）登记。两者同配置则一次重建同时归属于两个身份；不把 GT 选择称为严格无标签。

SART 上限150 sweep，变分上限200迭代；仅按输入目标的相对变化停止，统一 tolerance=1e-5、连续8次、最少30/40迭代。最大预算、候选、尺度、停止规则和数值源码哈希在校准前登记；train 数值失败可作为失败记录，Val 不追加搜索、不据 H/GT 选轨迹或重试调参。固定迭代目标稳定不是全局最优证据，预算耗尽必须保留。

## 5. 指标、统计与成本

沿用冻结 VolumeMetrics：relative L1/L2 无量纲，MAE/RMSE 与峰值绝对误差为质量分数；积分浓度 proxy 为 `abs(sum(C)-sum(GT))/sum(abs(GT))`，不是 kg 甲烷总质量。ppm·m 测量统一通过冻结 P_diff/K96 重投影，保存输入与共同 H4 relative L1/L2；另存自身求解目标残差和 SART 两种离散化差异。

先对同 case 的5draw平均，再做36-case配对 bootstrap，固定 seed2026101304、10,000次重采样、percentile95%区间。算法间、同算法布局间分别比较，不把射线或180条 draw 当独立样本。多重比较未校正，单seed网络和工况家族相关性明确限制结论。

按 case 保存稀疏算子构建/缓存查找、迭代、chi→C 转换、最终评价开销，网络仅前向计时。记录实际迭代、停止状态、GPU分配/保留内存及进程 RSS。站位算子几何缓存重用必须报告冷构建总成本与未缓存的等价成本；变分 P_diff 不做持久网格缓存。共享 GPU 的速度结果是当前环境实测，不能视为专用硬件基准。

## 6. 边界及下一阶段

本轮不训练网络、不追加蒸馏、模块或先验，不使用 Pool B、最终 test 或 GT128。数据读取由独立校准/评价审计约束；原自监督 GT read guard 不变。数据、checkpoint、大型算子及重建体积保存在外部独立目录，不提交 GitHub。

依据实际配对结果判断网络优势出现的布局/标签条件、所有方法共同变差的布局，以及未收敛预算是否限制解释。经典高误差不是理论下限；未收敛不得包装成网络优势。优先考虑下一阶段一次匹配的几何分层采样训练，但只在本次实测报告后提出建议，**不自动执行**。
