**项目：GeoPhy-Set3D｜版本：1.0｜调研截止：2026-10-15（北京时间）**

**交付性质：文献调研、既有证据核查、候选网络设计与实验方案。新方案尚未训练，本文没有生成新的重建精度结果。**

## 0. 决策摘要

建议将论文问题表述为：**在半圆移动站位、扇形逐束扫描、视角数量与分布变化的条件下，利用已知射线几何与路径积分测量，以不使用三维体场标签的训练方式，直接恢复三维甲烷浓度场，并量化困难几何下的精度和可信边界。**

最值得优先验证的路线是“集合几何初始化＋可微物理迭代展开”；最值得作为独立备选的路线是“集合条件连续浓度场”。高斯基元路线适合作为第三候选和表示对照；含流动方程的时空网络需要额外时序和速度信息，暂不作为当前静态末帧论文主线。

关键判断如下。

1. **有必要评估视角组合，但不必把论文改成视角优化论文。** 在相同视角数、同一组射线、同一噪声实现上比较算法；用纯几何描述量预先分层，并保留连续误差曲线。不能只报告均匀大跨度视角，也不能用重建误差反过来定义“好几何”。
2. **自由视角不等于任意几何都能高精度恢复。** 少视角存在大量不可辨识自由度。网络是在数据约束和所学先验之间求解，不是消除了信息缺失。跨场景和未见几何的结果，比单一验证集的平均误差更有说服力。
3. **“物理损失＋自监督＋三维网络”不足以单独构成新颖性。** NILAT、NAF、几何反投影网络、深度展开和高斯层析已有直接先例。应围绕一个具体机制提出可被否证的假设，而不是增加若干模块名称。
4. **已有仓库不是空白起点。** GeoLift、OARI、MRGR、双子集自监督、几何分层、DeepSets 对照等已经实现。新报告不把这些既有组件重新包装为新方案。
5. **现阶段不宜一味加强投影一致性或直接扩大网络。** 当前存在 128³ 参考投影与 64³ 表示的差异；困难几何增强已有普通精度受损的结果；MRGR 在极端组平均仍有帮助。因此需要分别检验表示、优化和先验泛化，而非先假设某个单一瓶颈。
6. **一区 Top 是成果目标，不是架构能够保证的结果。** 更有竞争力的证据组合是：公平强基线、跨种子结果、几何与物理失配测试、真正三维指标、实测或独立前向模型验证，以及诚实的失败案例。

## 2. 研究背景与科学问题

第一篇前作建立了主动吸收光谱、移动稀疏视点与三维甲烷层析的仿真链条，并比较了经典重建与采集参数。第二篇 LGV-Net 将 Bi-LSTM、注意力和卷积用于跨视角建模。用户说明其核心是二维重建后堆叠；本次看到的出版商摘要确认了相关网络组件，但没有独立核实其完整逐层实现。[R01](https://doi.org/10.1016/j.optlastec.2025.114639)、[R02](https://doi.org/10.1016/j.optlastec.2026.116045)

第三篇的增量应落在三个维度：

- **输入几何变化：** 同一网络接受无序、可变数量、非均匀分布的站位；输入真实空间位置、射线方向和有效掩膜，而非只把视角编号编码成序列。
- **真正的三维逆映射：** 在共享三维坐标中联合重建，射线按实际仰角穿过三维域；网络具有跨高度交互。输出形状为 64³ 并不能单独证明这一点。
- **不依赖体场标签的优化：** 训练约束来自观测方程、跨视角预测和适当先验；三维 CFD 场用于生成模拟测量及独立评价。

需要区分“算法直接输出三维体场”“由三维观测支持的唯一恢复”“学习了正确物理规律”。第一项可以通过实现确认，第二项通常不成立，第三项需要干预和泛化证据。可微投影器保证网络输出可以被物理方程检查，但不保证网络没有记忆有限工况。

建议研究假设：

**H1：** 在相同几何与测量预算下，显式射线梯度和几何预条件能比一次学习残差修正更稳定地利用观测，降低困难几何误差，同时控制普通几何退化。

**H2：** 条件连续浓度表示能减少离散表示偏差，并改善高浓度源区与空间细节；其收益必须与同预算高分辨率体素网络区分。

**H3：** 算子敏感性指标能够解释误差随视角组合变化的一部分规律，但不构成跨所有羽流的确定误差上界。

H1、H2 都是本报告提出的待验证假设，不是从已有数据得出的结论。

## 4. 现有 GeoPhy-Set3D：哪些已解决，哪些仍是瓶颈

### 4.1 源码核查后的真实结构

现有 SelfSup-MRGR v1 的链条为：

```text
每站 [路径积分浓度/全局尺度，有效射线掩膜，路径长度]
  → 共享二维编码器
  → 按射线几何提升到 32³ 三维特征
  → OARI 视角关系交互 + GCA 融合
  → 三维解码器 → C0: 64³
  → 可微射线积分 P_G(C0)
  → 带符号残差 Y−P_G(C0)
  → 残差二维编码、三维提升、特征修正
  → 共享融合/解码 → C1: 64³
```

模型报告参数量 332,070。源码可确认：残差带符号、采用固定 ppm·m 尺度、不将 C0 detach；输出 sigmoid；投影器 K=96；角度 lifting 用 atan2 恢复扫描坐标。OARI 的方向张量是局部方向多样性描述，源码注释也明确它不是完整 Fisher 信息矩阵。

现有 MRGR 是**学习的特征反馈**，不是严格的 `Jᵀr` 梯度下降或 proximal 算法。候选 A 的差异必须是显式算子更新与可检查的步长/预条件，而非把同一残差分支改名为 unfolding。

### 4.2 现有结果与可支持的结论

站位位置可写为 `o_v = (0.3,0.3,0.3) + (R cosθ, Δy, R sinθ)`。令 forward 指向域中心，`right=normalize(forward×world_up)`、`up=normalize(right×forward)`，则扫描射线为：

```text
d(α,β) = cosβ cosα forward + cosβ sinα right + sinβ up
α ∈ linspace(−5°,5°,64)，β ∈ linspace(−4°,4°,64)
```

数组行对应 β、列对应 α；三角函数实现需统一角度/弧度。64 为偶数，采样数组不包含精确的零角，不应把其中某个像素当作真实中心射线。每条射线与立方域相交得到 near/far；保留对应 valid mask 和物理交段长度。

### 5.2 两条投影链不能混用

原始 Fluent 数据说明中的旧 `inputs/` 来源为非结构网格积分；**当前 Projection Pool v1 忽略旧 inputs，重新从 128³ 质量分数插值积分生成**。因此当前训练参考与可微网络投影虽然实现不同，仍共享规则网格场表示与相近积分假设。

当前链条：

```text
Fluent 原生场 → 128³ 质量分数 C128
              ├→ 独立 C++ 参考投影，K256，梯形法 → 固定测量 Y
              └→ 端点对齐重采样 C64 → 仅评价/监督对照

网络输出 C64 → PyTorch 三线性采样 → 摩尔分数转换 → K96 中点积分 → 预测测量
```

这种独立实现校验降低了软件自证风险，但没有完全消除 inverse crime（生成与反演共享过于相同的模型）。建议增加真正独立的非结构网格积分或实测测试轨道。

### 5.3 从质量分数到路径积分浓度

设 `C(x)` 为 CH4 质量分数，`χ(x)` 为摩尔分数。采用两组分近似：

```text
χ(C) = (C / M_CH4) / [C / M_CH4 + (1−C) / M_air]
M_CH4 = 16.043，M_air = 28.965（两者使用相同摩尔质量单位）
Y_r = 10^6 ∫_[射线与重建域的交段] χ(C(o_r + s d_r)) ds + ε_r
```

`Y_r` 单位 ppm·m，`s` 单位 m，`d_r` 为单位向量；射线穿出域外后的背景若非零，真实系统要显式扣除或建模。本项目数据默认只积分重建域交段。

该映射对 `χ` 是线性的，对质量分数 `C` 一般是非线性的。尤其要遵守现参考的顺序：**先对质量分数做空间插值，再转摩尔分数，再积分**。预先把体素转成 χ 再插值不严格等价。若新方案直接表示 χ，需声明离散前向模型改变，并做独立投影一致性核查。

反转换为：

```text
C(χ) = χ M_CH4 / [χ M_CH4 + (1−χ) M_air]
```

真实吸收光谱满足光学厚度的路径积分；从吸收强度换算 PIC 还依赖谱线、温压、背景和仪器标定。现有网络输入已经是反演后的 PIC，因此本阶段优先把正确的 PIC 算子做扎实；没有原始光谱时，不宣称已联合解决光谱反演和浓度层析。

### 5.4 精度限制与源区分辨率

旧说明泄漏孔约 10 mm×10 mm，而 64³ 端点步距约 9.524 mm，孔宽只对应约一个网格间隔。另一方面，6 m 距离处水平角步长 `10°/63` 对应中心附近约 16.6 mm 的射线间距，垂直 `8°/63` 对应约 13.3 mm。以上是局部小角度估算，不能直接等同系统空间分辨率，但提示源区峰值受网格与射线采样共同限制。

多视角交叉和先验可能改善定位，无法凭把输出上采样到 128³ 就证明恢复了真实高频信息。连续表示的主张也必须通过高分辨率独立 GT、峰值和位置误差来验证。

当前全训练集审计给出的 pooled relative L1：同 128³ 场下算子差约 0.0958%；朴素 C64 对参考的差约 1.3993%。二者不能相减当作严格独立误差分解。12 例有限体积优化后的平均 fit L1≈0.6244%、held-out≈1.5774%，是特定初始化和预算下的结果，不是理论 capacity floor。[E09](https://github.com/JiachengDong2026/GeoPhy-Set3D/blob/3f563f0f86b38983fdfb4ab926641d5ec2f33adb/docs/reports/representation_capacity_64_v1.md)

### 5.5 为什么不直接给静态单帧加 Navier–Stokes 损失

适用于质量分数的输运约束应从守恒形式出发，例如：

```text
∂(ρC)/∂t + ∇·(ρuC) − ∇·(ρD_eff ∇C) = S
```

只知道末帧 C，通常不知道时间导数、完整速度场、有效扩散和源项。把 `∂/∂t=0` 当默认，或用来流风速代替近喷口三维速度，都可能施加错误物理约束。甲烷高浓度区还有密度变化；简单常密度被动标量方程不是无条件成立。

当前静态方案以测量物理、边界掩膜和有依据的弱正则为主。时间戳、连续帧和速度信息充足后，再考虑第 8.5 节时空路线。不能把“写了 PDE”当成“可解释性更强”的充分条件。

## 6. 自由视角组合：评估、分层与可辨识性

### 6.1 结论：先建立评价坐标系，不先筛掉困难样本

算法论文应固定一套几何评价协议，再比较不同算法在同一输入下的性能。分层的目的是避免平均数掩盖失败区域，不是把低信息几何移出研究范围。

建议保留现有 G1–G5 作为历史对齐轨道，另外建立前瞻几何集。原 G1–G5 基于中心方向分数分位数，G5 又额外要求跨度≤5°，并非自然总体的五个等概率等级。新分组不得覆盖旧命名；用 `geometry_protocol_v2` 独立记录。

### 6.2 从便宜代理到实际算子的三层指标

**第一层：站位分布。** 记录视角数 V、方位跨度、最大角间隙、最小成对锐角、站位间距、半径和高度范围。全部仅依赖几何。需注意两条相反方向的同一直线积分具有相同空间路径，跨度接近 180° 不一定意味着信息互补；应同时计算无向夹角 `acos(|d_i·d_j|)`。

**第二层：域内真实射线覆盖。** 在固定物理坐标网格上统计每个小体积被多少条有效射线、多少个不同站位穿过，统计未覆盖比例和路径长度分布。以射线管/离散积分基函数定义覆盖容差，不把一条数学零宽射线的“经过”误当稳定体积覆盖。方向张量可定义为：

```text
T(x) = Σ_r w_r(x) d_r d_rᵀ / [Σ_r w_r(x) + ε]
```

它表征方向多样性。近水平半环下，竖直特征值天然可能很小；低值不等于三维每个高度都完全不可测，高值也不等于可逆。现仓库用站位至查询点的方向，属于几何代理；实际离散射线及其支持范围是更严格一层。

**第三层：离散前向算子或局部 Jacobian。** 若表示为 χ，建立稀疏线性 `A_G`；若保持现有质量分数与插值次序，使用 `J_G(C)=∂P_G(C)/∂C` 的算子乘积。报告可用的奇异谱、稳定秩、有效秩和保留子空间条件数。不要把小型粗网格谱叫作完整 64³ 可观测性。

采用对称正定噪声协方差 `Σ` 时，`JᵀΣ⁻¹J` 才是高斯观测模型下的局部信息矩阵。方向张量 `T` 与它不同；真实浓度相关的 Jacobian 也不能在测试时用 GT 构造。可以用固定常量场、几何线性 χ 算子作独立诊断，或用当前预测作近似并显式标注。

### 6.3 稀疏三维恢复为何不可能无条件唯一

64³ 网格共有 262,144 个未知量。即使 6 站每站全部 4096 条射线都有效，总测量也仅 24,576；线性 χ 模型的秩最多为测量数，零空间维度至少 237,568。实际无效射线和相关性会进一步减少有效约束。

非线性质量分数模型的局部 Jacobian 同样至多具有相应测量数的秩。非负、边界、低维流形和统计先验可以限制可行解，但不能因此声称任意 64³ 浓度场可唯一恢复。跨案例训练学到的是羽流族先验；泛化到不同源位置、源数、风场、边界和仪器误差必须测试。

**建议做一个直观的歧义实验：** 在固定输入射线上构造两个非负、可接受的场，使测量差低于已登记噪声/数值容差，但体积差明显；再增加一个互补视角检查差异能否被观测。此实验是展示信息边界，不以 GT 生成部署输入。若使用数值优化寻找场对，须报告所用表示和有限优化预算，不把找不到歧义当作唯一性证明。

### 6.4 前瞻几何测试设计

| 轴 | 建议水平 | 解释 |
|---|---|---|
| 视角数 | 主测试 V=3/4/6；压力测试 V=2/8 | V=6、8 对现 v1 的训练 3–5 属数量外推，不隐瞒 |

| 采集族外 | 超出训练半径/高度/扫描密度的受控变化 | 保证真实覆盖后再比较，分开报告 |

每个 V×布局族先固定至少 10 个布局用于主比较；旧 25 个 V4 布局用于历史重放。抽样种子、排除规则、候选池大小和未能满足的组合均保存。不能因为某布局误差太高而删除；无可行覆盖的布局可单列“采集不可用”，规则必须在看到重建结果前给出。

**自然分布与压力分布分别汇总。** 不能让人为大量生成的极端组占据总体平均，也不能只给最有利的自然均值。若需要单一总分，预先冻结业务权重，而不是看结果后决定。

## 7. 所有候选方案共用的自监督与数据协议

### 7.1 “无标签”需要说清三层含义

1. **无体场标签梯度：** 网络参数更新不读取 C_GT，也不使用由其产生的逐体素伪标签。
2. **无体场标签选模：** checkpoint、早停和超参数仅依据独立留出测量；监督权重不得 warm start。
3. **整个研发过程未接触体场 GT：** 连结构、研究方向和阈值都没有受 GT 诊断影响。

当前研究已参考历史 Val GT 结果，因此第三种最强声明不成立。本报告建议准确使用“训练与 checkpoint 选择不使用 volumetric GT”；同时披露研究设计参考了开发集评价。测量本身由 CFD GT 合成，也应明确写出，不能声称完全不依赖模拟场。

冻结统计文件可能同时含投影和 GT 统计；自监督入口应只允许投影统计字段。不能以“没有打开 GT.npy”为由忽略从缓存读入 GT 均值、占据率或源位置等泄漏路径。

### 7.2 当前协议作为首轮公平比较的共同底座

沿用现 v1 的成对不交子集：训练 A、B 各 3–5 站，H=2 站；验证固定 A4/B4/H4。网络分别只接收 A 或 B，H 从不进入重建网络。训练使用的同案例总观测数是 A+B+H，约 8–12 站；推理时才是单独 3–5 站。应披露这一训练观测预算，不能让读者误以为训练也只需每例 3 站。

```text
C_A = fθ(Y_A, G_A)，C_B = fθ(Y_B, G_B)
L_hold = 0.5 [D(P_H(C_A),Y_H) + D(P_H(C_B),Y_H)]
L_cross = 0.5 [D(P_B(C_A),Y_B) + D(P_A(C_B),Y_A)]
L_obs = 0.5 [D(P_A(C_A),Y_A) + D(P_B(C_B),Y_B)]
L_cons = mean_case {mean|C_A−C_B| / [0.5(mean|C_A|+mean|C_B|)+10⁻⁶]}
L_v1 = L_hold + 0.5 L_cross + 0.1 L_obs + 0.05 L_cons
```

`D` 为现有按有效射线计算的归一化 SmoothL1（β=0.01）加 0.1×sample-relative L1。首轮只比较架构时保持它不变。如果更改损失，必须另设因子实验，不能将结果全归因新架构。[E10](https://github.com/JiachengDong2026/GeoPhy-Set3D/blob/3f563f0f86b38983fdfb4ab926641d5ec2f33adb/src/geophy_set3d/training/selfsup.py)

视角 padding、真实零射线和无效占位分别处理。所有 masked 运算应在除法、归一化和 attention 前屏蔽无效值，不能依靠 `NaN×0`。只给均值聚合时额外提供真实 V/覆盖量，避免遗漏观测数量的信息。

### 7.3 划分层级与泄漏防护

按 CFD case/trajectory/重复场内容分组，再分训练、开发验证与最终测试；同轨迹不同帧不能随机落在不同 split。孔布局家族相同的相邻压力/风速工况仍可能高度相关，当前 166/36/35 不等于跨家族验证。

保留已有冻结划分用于主比较；另外建立按几何家族留一、源强范围留出或风速范围留出的独立研究轨道。不要把这类重划分结果与原训练/测试身份混在一起。最终测试集一旦打开，其结果只能报告；后续改模需要新的确认数据。

H 是该阶段的留出测量，不等于最终盲测。反复用 H 选 epoch 后，报告 H 性能属于验证性能；可以另设不参与选择的 U 测量集用于一次评价，最后由独立体场测试检查三维准确性。

### 7.4 噪声和模型误差应分别建模

建议使用：

```text
Y_obs,r = (1+g_view) P_(G_true),r(C) + b_view + ε_r
网络收到 G_obs = G_true ⊕ δG
```

其中独立加性噪声、站级增益、基线漂移和几何扰动是不同因素。SNR 定义冻结为有效射线上 `20 log10(RMS(Y_clean)/σ)`；零信号样本改用仪器噪声底或固定 σ，不能用零分母定义 SNR。

对独立、条件零均值噪声，留出测量的平方误差可在适当假设下估计无噪声预测误差加常数噪声项；站级共模误差、相关漂移或裁零后的噪声不满足相同假设。不要把“随机拆射线”当作噪声独立性已满足。主协议优先按站留出；同时建模跨站共享标定误差，必要时按独立采集批次留出。

几何不正确时，网络可通过改变 C 吸收位姿误差。先分别测试已知扰动的鲁棒性，只有标定先验充分才联合估计少量校准参数；固定参考站或约束整体位姿，避免场移动与传感器移动之间的 gauge 歧义。

### 7.5 可选损失改进：只能作为独立实验

- 对近零测量，避免逐射线 `|e|/|y|`；使用训练测量给出的全局噪声底，逐案例分母也需预登记。
- 若已知仪器 σ 和前向离散误差尺度，可用加权 Huber 或白化残差；尺度只从训练/独立标定确定。
- TV、稀疏或流向平滑正则可能减少伪影，也可能抹去峰值、分叉和多源。默认不堆叠，逐项消融。
- A/B 三维强一致性可能促使不同观测都输出平均模板。取消或改成低频一致性只是待检验假设；RVTC 的结果不能直接代替这一消融。
- 不用可自由增大的学习噪声方差“解释掉”所有残差；若估计噪声，需独立标定、上下界和对数似然项，并报告残差是否被系统性忽略。

## 8. 候选网络方案

### 8.1 四方案比较与推荐次序

以下为研究设计，不是已经实现的模型或性能承诺。

| 方案 | 核心差异 | 适配当前数据 | 预期优势（假设） | 主要风险 | 优先级 |
|---|---|---|---|---|---|
| A：几何条件物理展开网络 | 显式残差梯度、预条件、有限步三维先验 | 高，复用现有投影与集合编码 | 可解释、可对照、控制更新稳定性 | 反传成本、离散误差、坏几何仍欠定 | 首选主线 |
| B：集合条件连续浓度场 | 三维特征条件化的坐标函数，直接连续积分 | 高，需新查询解码/积分接口 | 减少表示偏差、分辨率灵活 | 高频幻觉、计算量、不保证新增信息 | 独立备选 |
| C：正值高斯基元场 | 集合编码预测三维高斯，有限线段积分 | 中，需新表示与渲染器 | 稀疏紧凑、羽流团块表达、积分高效 | 细节/高浓度约束、与已有高斯层析竞争 | 第三候选 |
| D：时空输运约束场 | 时间戳观测＋浓度/速度联合建模 | 当前末帧不足 | 处理扫描期间演化、时空一致性 | 不可辨识速度、错误 PDE、额外数据需求 | 后续方向 |

主论文宜聚焦一个主方案与必要组件消融；不建议四套大型方法同时铺开。先用小预算证据决定 A/B；C 可作与 B 不同表示的独立对照。

### 8.2 方案 A：集合初始化＋几何条件物理展开（首选）

#### A1. 结构与数据流

```text
{Yv, Gv, maskv} 无序集合
  → 共享 2D encoder + 真实角度 lifting
  → 对称融合 / OARI（明确为既有可复用模块）
  → 初始三维 C0
  → [可微投影 → 白化/鲁棒残差 → 精确 Jacobian 转置
     → 几何预条件更新 → 小型 3D 先验模块] × K
  → 最终 C_K + 残差/更新幅度诊断
```

起始设计：特征宽 32，lifting 32³，输出 64³，K=4，共享迭代先验权重；每步先验为 3D 残差网络，3 个 3×3×3 残差块，32 通道，GroupNorm/SiLU。输入先验通道包含当前 C、物理更新、覆盖量、几何敏感性代理及步数嵌入。上述是初始实现选择，不是搜索后的最优配置。

第一轮采用 mean/DeepSets 初始化作独立机制检验，第二轮再接既有 OARI 初始化；这样可判断收益来自物理展开，还是原有 OARI 本身。另设“增加相同参数但不做算子更新”的控制。

#### A2. 保持现有物理的更新公式

令 `p_G(C)=P_G(C)/s_Y`，`r_k=p_G(C_k)−Y/s_Y`。对加权鲁棒数据项 D，定义 `ψ(r)=∂D/∂r`，`J_k=∂p_G(C_k)/∂C_k`：

```text
g_k = J_kᵀ ψ(r_k)
D_k ≈ diag(J_kᵀ W J_k) + λI
Z_k = Π_[0,1] [C_k − τ_k D_k⁻¹ g_k]
C_(k+1) = Π_[0,1] [Z_k + a_k Rθ(Z_k, g_k, geometry_features)]
```

`Π` 是物理范围投影，`D_k` 为正对角预条件，`τ_k` 为受约束正步长。低覆盖区不做未经限制的除法，`D_k` 必须有尺度明确的下限。精确平方 Jacobian 对角若成本过高，可用多次随机探针估计或几何覆盖代理；明确区分“预条件代理”与“真实对角”。估计不读取 GT。

`a_k` 为有界的学习残差幅度，`Rθ` 输出浓度修正。它不按几何分数简单开关，也不预设坏几何应关闭修正；相应设计必须与已有 MRGR 在 G5 平均有益的证据相容。

首个可实施版本固定几何预条件，采用有限的步长上界和残差幅度上界；随后才评估更精细的局部 Jacobian 预条件。新输出若使用硬 clip，要检查饱和区梯度；若用 sigmoid 参数化，要检查低浓度区梯度衰减，不能只看总 loss。

#### A3. 实现与收敛解释的边界

对线性 χ 模型、凸二次数据项、固定预条件和适当步长，物理梯度步骤有经典下降解释。对当前非线性 C 模型和任意学习残差先验，**整个网络没有自动的全局收敛或单调改善保证**。可设置仅依赖输入测量的固定次数回溯作为保护，但其耗时、额外前向与分支需要计入；低输入残差也不能保证低三维误差。

训练通过 `Jᵀr` 反传可能需要二阶导数。当前 `grid_sample` 路径能做一阶 autograd，不等于所用设备/版本支持所需二阶路径。实现前先做 double-backward 检查；如不支持，可按相同三线性权重构建稀疏采样矩阵与 scatter/gather 的显式伴随，或实现可验证的自定义 VJP。若选择 stop-gradient 近似，必须作为不同方法报告，不能写成完全端到端精确展开。

#### A4. 为什么可能改善

现 MRGR 学习如何从二维残差改三维特征；A 显式给出每条射线误差对三维未知量的敏感方向，减少网络自己学习反投影的负担。预条件用于平衡射线覆盖/灵敏度差异，学习先验补足欠定部分。关键假设是这些结构在变几何下比固定一次反馈更稳定，而不是“物理更多必然更好”。

必要对照：相同初始化下 K=1/4；无预条件/几何预条件；精确梯度/同容量学习残差；无先验/有先验；共享/不共享权重仅在预算允许时比较。几何增强单列为另一因子，不能同时加入后只报综合提升。

**停止条件：** 若小样本中输入拟合改善但留出测量持续恶化，或正常几何收益依靠增加大量迭代时间，先诊断表示和噪声拟合，不直接把 K 从 4 扩到几十步。若 A 不能优于合理收敛的经典求解器和原 MRGR，则保留负结果，转 B。

### 8.3 方案 B：集合条件连续浓度场（独立备选）

#### B1. 与逐案例 NAF/NILAT 的差异

网络在训练案例之间共享参数；每次从稀疏测量集合提取条件特征，输出任意三维坐标处的浓度。主模型无需为每个测试案例从零训练。NAF/NILAT 类逐案例优化作为独立对照；任何测试时微调另设轨道和耗时。

#### B2. 推荐结构

```text
每站 2D 特征 → 几何 lifting → 对称集合融合 → 32³/64³ 三维特征金字塔 F
查询 x → [三线性读取 F(x), 归一化 xyz, 低频位置编码, 局部射线覆盖描述]
       → 4 层、宽 64 的共享 MLP → sigmoid → Cθ(x | measurements)
射线积分：在连续坐标 x_rq 上查询 Cθ，再做 χ(Cθ) 转换并积分
```

优先用三维特征网格而不是立刻换成 tri-plane，避免薄结构的平面因子化偏差与高频编码两个因素同时变化。位置频率从低频开始、按固定日程开放有限高频；不要默认高频 hash 编码越多越好。

初始查询解码器可由独立的平均/DeepSets 聚合输入，随后再做 OARI 版本。输出 C64 和 C128 都是同一连续函数的采样，不把 C128 插值图误当独立高分辨率证据。

#### B3. 积分与表示一致性

训练直接对连续函数积分，而非先离散成 64³ 再投影。主参考仍用既有 Y128，避免把新模型自己的投影当标签。训练从 K96 起步并分块查询；冻结模型后比较 K96/192/384 的积分收敛，误差不足以满足预登记容差才增加采样预算。

也可直接输出 χ，但必须与质量分数输出形成单独对照，因为非线性变换与空间插值不交换。主方案建议先输出 C，以保持物理变量和训练解释一致。

#### B4. 训练成本与抽样

V4×4096×K96 约 157 万查询点/单次投影（未扣无效射线）；双输入/留出投影会成倍增加。使用 ray chunk、坐标 chunk、缓存几何坐标及必要的梯度检查点。FP32 积分，网络部分混合精度只有通过数值核查后才启用。

若从全射线改为随机射线小批量，需要对同一损失目标做适当抽样权重；每个病例的 relative-L1 分母可用完整已知目标预计算。不能让随机比例之比被当成全量比值的无偏估计。正式选模/评价仍使用全有效射线，并给所有比较方法相同的训练信息预算。

#### B5. 风险、可解释性与验收

连续函数不会创造缺失视角信息，高频解码可能沿未观测方向产生虚假纹理。重点检验：跨分辨率积分收敛、未见射线误差、源区峰值/位置、空背景假阳性，以及粗到细误差是否在独立 GT 上同步改善。

关键对照为“64³ 体素”“128³ 体素”“相近参数/训练时间的连续解码器”“逐案例 INR”。若连续表示只在自身投影器上更好、独立投影器和三维指标没有改善，不支持其作为主创新。

### 8.4 方案 C：集合条件正值高斯基元浓度场

#### C1. 表示

以摩尔分数场为例：

```text
χ(x) = Σ_(j=1..M) a_j exp[−0.5 (x−μ_j)ᵀ Σ_j⁻¹ (x−μ_j)]
a_j ≥ 0；Σ_j 正定；μ_j 位于域内或限定的边界邻域
```

共享二维编码＋几何特征集合由 M 个可学习查询读取，输出中心 μ、尺度/旋转、幅度 a。首轮 M=256，另以 M=128/512 做表示敏感性，不将不同 M 的最佳结果混为一个固定预算模型。中心与尺度采用有界参数化，限制过细/极端扁长基元。

非负混合**不保证 χ≤1**。两种可行选择：一是保留线性混合与解析积分，施加足够密的上界审计和约束，但承认抽样约束不保证全域；二是用 `χ=1−exp(−Σ a_j φ_j)` 保证上界，此时不再具有简单的逐基元线性积分，要数值积分。不能同时宣称严格有界和未经修正的线性解析投影。高浓度喷口使这一点尤其重要。

#### C2. 有限线段解析积分

令一条射线 `x=o+td`，`Q=Σ⁻¹`、`h=o−μ`、`a=dᵀQd`、`b=dᵀQh`、`c=hᵀQh`，则单基元从 near 到 far 的积分为：

```text
amplitude × exp[−0.5(c−b²/a)] × sqrt(π/(2a))
× {erf[sqrt(a/2)(far+b/a)] − erf[sqrt(a/2)(near+b/a)]}
```

这里 amplitude 与二次型系数 a 是不同变量；实现时使用不同名称。只有单位方向 d 和正确的域交段才能保证长度单位。数值上要处理极小尺度、远尾 erf 相减及下溢，并与独立积分校验。

解析线积分和高斯层析已有 R²-Gaussian 及 2026 ray-tracing 工作，不能作为独创；研究重点应是从变视角集合到气体定量场的前馈建模、非负/上界处理及公平的无标签训练。

#### C3. 适用性与风险

羽流平滑团块和细长结构可能适合各向异性高斯，输出也便于多尺度采样；但多孔近源尖峰、分叉和湍流小尺度可能需过多基元。M=256、V4 时单轮大约有 419 万 ray–Gaussian 对（全射线计），解析积分也不等于免费计算。

以同预算逐案例高斯优化与前馈高斯预测分别比较。总量可从有限域积分得到，但只有结合密度/摩尔质量才能称实际质量；不要把基元幅度之和当 kg。若细节与峰值始终被抹平，则保留为低成本基线，不强行用于主论文。

### 8.5 方案 D：时空浓度场＋输运约束（条件性扩展）

适用前提：取得真实连续帧、每条射线时间戳、扫描顺序、可信速度/边界信息或可辨识的低维流动参数。输入应为 `{Y_r,o_r,d_r,t_r}`，输出 `C(x,t)`，而不是把不同时间站位当同一瞬时场。

推荐先测试已知速度/密度的输运约束，再考虑联合估计低维速度修正。初始结构可沿用 B 的空间特征与时间编码，增加速度分支和守恒残差；源项只在已知物理边界范围施加，不把每个体素都设自由源项来吸收误差。

若只有末帧 C，没有 u、∂C/∂t 和边界，D 不是当前可执行主方案。若所有 Fluent 原生时序场可用，可开展独立 4D 论文，重点从“静态重建”转为“顺序扫描导致的动态失配”。这比在静态论文中加入未经核查的 PDE 更明确。

### 8.6 推荐的实际选型逻辑

先保留原 v1 和 DeepSets 的冻结基线；完成 A 的精确算子/梯度小样本检查，同时把 B 做成最小条件场原型。若 A 在相同预算下显著改善测量外推且不引入明显离散拟合问题，进入主训练；若主要改善集中在输入拟合、源区表示仍受限，优先评估 B。C 用于检验“换表示是否比复杂展开更有效”。D 等额外数据明确后另行立项。

这不是预言 A 一定最好，而是按现有可复用代码、可解释性、研发风险和文献竞争综合排序。最终选择须由前瞻协议的结果决定。

## 9. 测试与验证：怎样才足以支撑论文结论

### 9.1 基线按信息条件分组

| 组别 | 必要方法 | 公平比较要求 |
|---|---|---|
| 无学习经典算法 | 非负最小二乘/带边界拟合、3D Tikhonov、3D TV、适用的 SART | 使用同一真实几何、有效射线和单位；在 χ 空间求解时转换并解释离散差异 |
| 自监督前馈学习 | 冻结 SelfSup-MRGR v1、DeepSets、几何提升＋3D decoder、候选 A/B | 同 case split、观测预算、loss/selector 或明确因子变化；不能只比较弱基线 |
| 独立模型式学习 | 使用相同自监督协议的 3D Learned Primal-Dual 任务适配 | 不借监督预训练；披露原方法与适配差异，验证可学性 |
| 逐案例无外部训练 | NAF/NILAT 思路的三维 INR、DIP＋TV、可行时高斯优化 | 测试时只能使用当前输入测量，完整优化耗时计入；禁止用测试 GT 早停 |
| 监督参考 | 原监督 MRGR、LGV-Net 任务适配、必要的监督三维网络 | 单独表格，用来估计监督差距；不是数学上界，也不是纯自监督排名 |

TV/Tikhonov 必须做合理收敛诊断和正则强度选择；用验证测量或预登记的 discrepancy/L-curve 规则，不能故意给极少迭代后称“经典算法下限”。固定临床 CT 的 FDK/FBP 在本题扫描几何下未必适用，不能用不匹配的投影器制造差距。Poisson 似然若用于 OSEM/MLEM，也要说明与已反演 PIC 噪声是否相符。

LGV-Net 原来若要求固定视角或切片形式，原样评价与改成可变几何的适配应分别命名。不能把不适用的输入直接送入原模型，再用失败结果宣称新模型全面优于前作。

### 9.2 核心实验矩阵

| 编号 | 问题 | 控制条件与输出 |
|---|---|---|
| E0 | 物理/几何实现是否正确 | 零场、常量场、非对称仿射场、偏心球、射线边界、单位；一阶/必要时二阶梯度与伴随检查 |
| E1 | 是否依赖测量而非模板 | 同几何换案例测量、置零、打乱视角配对、有限幅度扰动；检查输出和留出误差变化 |
| E2 | 自由视角同条件精度 | V=3/4/6×布局族，固定 case/layout/noise，保存所有预测后独立 GT 评价 |
| E3 | 数量和站位泛化 | V=2/8 外推；Pool B 明确是已开发域；另生成未使用的站位清单用于确认 |
| E4 | 噪声鲁棒性 | clean、40/30/20/10 dB；加性噪声主线，共模增益/漂移另测 |
| E5 | 几何/标定失配 | 方位/仰角 0.05°/0.1°/0.5°、平移 1/5/10 mm；建议压力级，实测标定后再冻结正式值 |
| E6 | 模拟前向模型偏差 | 规则网格生成/反演对照；独立非结构网格、不同采样核、光束宽度或实测 |
| E7 | 流场先验泛化 | 留出源布局、源数或强度/风速范围；同轨迹组不拆开；单独训练身份 |
| E8 | 解释性与组件必要性 | 下节消融、物理迭代曲线、已观测/未观测方向干预 |
| E9 | 实用代价 | batch1 端到端、纯网络、投影、优化总时长、显存、参数量、冷/热启动 |
| E10 | 实验可用性 | 稳定气袋/可控释放、独立留出路径浓度、定位参考与标定；动态扫描时记录时间 |

不要第一轮把所有维度全因子相乘。先在干净已标定条件下比较主要架构；再对冻结的少数候选做单因素鲁棒性，最后在预登记的少量联合最坏条件上验证。一次只改变几何时，所有算法收到同一组测量，不使用“为了某算法更适合”而改变站位。

### 9.3 必须报告的指标与定义

以同一物理网格的参考 C 与重建 Ĉ 为例：

```text
relative L1 = Σ|Ĉ−C| / max(Σ|C|, ε_L1)
relative L2 = sqrt(Σ(Ĉ−C)²) / max(sqrt(ΣC²), ε_L2)
NMSE = Σ(Ĉ−C)² / max(ΣC², ε_NMSE)
MAE = mean|Ĉ−C|；RMSE = sqrt(mean(Ĉ−C)²)
```

相同非零分母且未触发保护时，NMSE 是 relative L2 的平方；不能混写。ε 按预先固定物理尺度设定，并对近零/无羽流案例单列，不能借大 ε 隐藏失败。

**主终点：** 每案例三维 relative L1，分别给自然几何宏平均与困难几何；保留 L2/RMSE 辅助以反映峰值误差。**其他必要终点：** 峰值绝对误差、峰值位置/源位置偏差、阈值体积与连通结构误差、背景假阳性、独立留出射线误差、时间/显存。

阈值分割要用固定绝对浓度门限或仅由训练/标定确定的门限，并报告多个预设门限敏感性。不要用每张 GT 峰值的百分比来宣称可部署性能。多源定位需固定匹配规则，如匈牙利匹配加漏检/虚警惩罚；浓度峰并不总等于泄漏孔位置，要区分任务定义。

`ΣC` 是网格浓度和代理；物理质量是 `∫ρC dV`。对端点采样，应采用相应体积积分权重；若使用密度混合模型从 C 得到 ρ，应单列假设。静态浓度场本身不能唯一确定泄漏质量流率，需要速度/边界/输运模型。

PSNR/SSIM 可辅助显示，不作为唯一指标。PSNR 的 data range 使用固定物理范围，不能每例使用自己的峰值；3D SSIM 或逐切片 SSIM 的定义必须注明。二维最大强度投影只能辅助观察，可能隐藏深度错误，需同时提供三正交切片和三维结构。

### 9.4 消融设计：避免“多模块一起换”

最小必要消融分两步。

**结构比较：** 同一自监督训练目标下，DeepSets/简单 lifting 基础、既有 OARI、既有 OARI+MRGR、候选 A、候选 B；对 A 另保留等参数无显式物理步骤控制。C0/C1 内部差异只作诊断，不替代“有无模块从头训练”的消融。

**机制比较：** 选定主要结构后，再检验预条件、迭代数、连续/离散表示、loss 中 observed/hold/consistency 的必要性。若测试几何增强，采用 Base、Base+增强、Base+新机制、Base+两者的 2×2 设计；不要将架构与采样变化混为同一贡献。

对于无 hold 或无 cross 等消融，避免悄悄减少总观测量造成信息预算混杂。可以同时给“原始删项”与“观测预算匹配”两种解释，明确各自回答的问题。随机置零、错配、符号反转是机制干预，不是正常鲁棒性输入分布。

### 9.5 可解释性证据清单

| 主张 | 可支持的检验 | 不能据此声称 |
|---|---|---|
| 确实利用测量 | 同几何真实/错配/零测量，对输出和独立 H 的影响 | 某个 attention 热点就是唯一物理原因 |
| 几何影响重建 | 固定病例和 V，只替换一个站位；与随机替换配对 | 把加站位的信息增益归为网络提升 |
| 物理步骤起作用 | 每步输入/留出残差、更新范数、三维后验评价 | 输入残差单调下降保证三维误差单调下降 |
| 先验在低信息方向起作用 | 近零空间扰动、频带误差和新工况测试 | 学到普适流体定律 |
| 不确定性有用 | 重复种子/输入噪声/标定扰动的分歧与误差关联 | ensemble 方差就是真实后验方差或严格置信区间 |

若报告 90%/95% 浓度区间覆盖率，需要独立有 GT 的校准/测试集或明确的概率模型验证；测量置信区间不能直接转为体素置信区间。仅 3 个训练种子可做稳定性分析，不足以宣称不确定性已完全校准。

### 9.6 统计单位与公平预算

- 主比较先对同案例同组布局取平均，再做配对 case bootstrap；同一案例的多个视角、射线、体素不是独立样本。
- 至少 3 个训练种子，资源允许时 5 个；报告每 seed 结果，不只挑最好 seed。跨 seed 与 case 的分层重采样应与研究问题相符；3 seeds 的不确定性估计仍有限。
- 若声称跨几何总体泛化，需对布局抽样变异也建模或使用独立布局重复，不能只给固定 25 布局下的 case 区间。
- 工况家族只有 6 种，家族间泛化不确定性不能靠几百万射线缩窄。附家族留一分析及逐家族结果。
- 主要终点、失败门槛、辅助指标和多重比较方式在训练前冻结。报告差值及区间；不能把各个未校正 95%CI 都叫作同时显著。
- 同信息条件优先；再给固定更新数和固定墙钟两条性能曲线。等参数不等于等算力，固定 2 小时不等于都收敛。共享 GPU 时间波动和额外测试优化均注明。

### 9.7 建议的工程参数与阶段门槛

以下是**建议初值/验收规则**，不是已完成结果或预计必达的性能。

| 项目 | 初始建议 |
|---|---|
| 训练数据 | 原 166 train，保留 36 Val measurement selector；不开放最终 35 test |
| 正式主比较 | 300 epoch、有效 batch=2、24,900 更新，与原 v1 对齐；同时测墙钟 |
| 优化器 | AdamW，lr=2×10⁻⁴、weight decay=10⁻⁴，cosine，clip=1，先 FP32 |
| 种子 | 至少 3 个固定种子；例 20261011/20261021/20261031（仅编号） |
| 小预算检查 | 固定 8 个训练案例，最多 2,000 更新或 30 分钟，两者先到即停 |
| 早期可学性判据 | 数值有限；H 误差优于零输出且较初始化改善；跨案例和测量干预响应非退化 |
| checkpoint 选择 | 固定 Val 独立 H relative L1；不按体场 GT 或最终测试选择 |
| 正式科学主张 | 同条件三维 L1 对强自监督基线改善，差值区间支持；并如实报告失败组 |
| 实用效果目标 | 可预登记自然域平均相对降低≥10%，或困难组降低≥20%且普通域恶化≤3% |
| 非劣检验 | 若声称统计非劣，普通域比值的适当单侧区间上界≤1.03；只有点估计≤1.03不够 |

可学性不能只以训练 loss 下降判定。对模型输出记录均值、空间方差、案例间差异、饱和比例，以及同几何错配测量响应；近零模板可能取得看似不错的背景损失。门槛应先用测量单位与验证容差固定，不因单模型失败不断放宽。

上述 GT 科学评价是冻结后的结果判定。若根据开发 GT 结果换模型，需披露其 GT-informed 研究选择；不可继续宣称全研发过程无 GT。最终 test 用于一次确认，不用于决定继续调参。

### 9.8 真实实验与时间一致性

最小实测闭环可用稳定气袋或可控静态浓度分布，完成路径长度、角度、PIC 标定和未输入路径预测。气袋与自由湍流羽流有域差异，能验证装置/几何和定量链条，不能单独代表真实泄漏泛化。

扫描采集时间需与流场变化时间比较。粗略平移尺度 `U·T_scan` 如果已接近或超过所需空间分辨率，静态假设就值得怀疑；这是筛查指标而非完整判据，喷流速度可能大于背景来流。应报告每条射线/每站时间、整轮时间与独立动态证据。

若仪器拿不到三维 GT，可用额外留出路径、点浓度、已知源位置和可控场作多源验证，但不要把仅路径吻合说成已证实三维真值。缺少实测时，论文定位应明确为 CFD 仿真方法研究。

## 10. 创新点、论文组织与投稿定位

### 10.1 建议的核心贡献表达

若 A 获得验证，可围绕以下三项组织：

1. 面向变数量、非均匀半圆采集的集合条件重建，在三维物理坐标中保持射线与测量的对应；引用已有 lifting/集合方法，不将基础组件当独创。
2. 面向气体浓度非线性变量转换及有限离散误差的物理展开机制；通过匹配消融证明它改善的是测量信息利用和几何泛化，而非仅增加参数或迭代预算。
3. 无体场标签训练下的严格定量评估：自然/极端几何、标定与模型失配、强独立基线、跨种子以及实验验证。

若 B 最优，第二项改为“集合条件连续浓度场与射线积分协同建模”，并用独立高分辨率评价证明表示收益。不要在未验证时同时声称解决了欠定性、实现了任意分辨率真实超分辨和学习了完整流体物理。

### 10.2 文献差异核查表

| 拟提出的点 | 最接近工作 | 至少需要的新增证据 |
|---|---|---|
| 几何提升 | R11 与本仓库 GeoLift | 当前新方法不能仅靠这一项主张新颖性 |
| 自监督吸收反演 | R04、NILAT、SSDU | 跨案例前馈自由几何、实际三维定量收益 |

### 10.3 论文建议结构与图表

正文：研究动机与与前作区别 → 测量模型与可辨识性 → 网络与自监督 → 数据/实验协议 → 同条件结果 → 机制、鲁棒性和真实实验 → 局限。

建议主图：①真实扫描几何与物理量；②网络结构及训练/推理信息边界；③同 V 的布局与误差分布；④三维正交切片/等值面及源区定量；⑤消融与每步物理残差；⑥噪声/标定失配；⑦实测留出路径与定位。主表分自监督、逐例优化、监督参考；不把不同标签预算混为统一名次。

期刊定位应按最终证据选择。若核心是通用逆问题方法，需证明超出单一气体场景的适用性；若核心是测量和环境监测，实测、定量标定和部署约束更重要。本文不宣称某具体期刊在投稿当年的分区或 Top 身份，投稿前应按所采用的中科院/JCR 口径核对最新版。

| P4：科学评价 | 先保存预测再读 GT；主表、消融、鲁棒性、时间 | 报告全部组与失败，不按 test 改模 |
| P5：独立确认 | 新布局、新前向模型/实测、最终 test | 方法/阈值冻结后一次确认 |
| P6：论文 | 方法、证据边界、可复现配置及负结果说明 | 结论与证据逐项对应 |

已归档自监督训练在共享 RTX 4090 上约为数小时级单 run；几何增强报告两臂各约 2.7 小时。新展开/连续场的成本可能显著增加，不能直接沿用该耗时作为承诺。P1 先测单步显存和 epoch 时间，再按 `候选数×种子数×正式训练时间` 估算总预算，加上基线逐案例优化和失配测试成本。

例如 4 个正式训练配置×3 seeds 就是 12 次训练；若每次约 3 小时，约 36 GPU·h 仅为量级示例，不含新模型放大和调试。若资源紧张，优先保留强基线与跨种子，减少低价值模块堆叠。阶段周期取决于数据、硬件与实测设备，本报告不给未经测量的完成日期保证。

**最优先的一项新研究实验：** 在固定原数据和自然几何采样下，对“相同集合初始化＋原一次 MRGR”和“相同初始化＋四步显式物理展开”做匹配比较，同时保留等参数学习残差控制。先确认精确梯度实现与小样本留出测量，再进入正式训练。若双重反传或成本不合适，先转条件连续场最小原型，不靠删减射线来隐性改变比较条件。

## 12. 待确认问题与默认处理

这些问题不阻碍完成本次调研；真正实施前需要用实际数据/设备回答。

| 待确认项 | 为什么影响方案 | 本报告采用的默认处理 |
|---|---|---|
| 原生 Fluent 全部时序场、u/ρ/湍流量是否可取 | 决定能否用输运 PDE、独立积分和动态扫描测试 | 当前只依赖已冻结末帧投影池 |
| 原始 CFD 物理质量/残差审计是否完整 | 旧说明中完整性与残差判据不同 | 不把数据生成成功等同 CFD 已重新验收 |
| 真实扫描顺序、每站时长、反射目标/光程定义 | 决定静态假设和 PIC 路径模型 | 静态已标定有限交段；真实系统需复核往返/背景因子 |
| 可获得多少独立实测与留出路径 | 决定实验验证层级 | 设计稳定场最小闭环，不虚构可用设备或 GT |
| “无监督”是否包含研发/选模都不许 GT | 影响历史结果使用和声明 | 严格保证未来训练/selector不读 GT，披露研发已看开发 GT |
| 首要目标是毫秒推理还是可接受逐例优化 | 决定 A/B 的步数、是否允许 test-time refinement | 主线前馈/有限步，逐例优化单独排名 |
| 是否要求高于 64³ 的实际空间精度 | 决定 B 与高分辨率体素对照 | 先64³公平主表，128³作为独立表示验证 |
| GPU 额度、最大显存与运行环境 | 决定候选数与训练预算 | 先测量成本，再固定有限配置；不默认无限训练 |
| 源位置、孔数、风速是否真实可知 | 影响是否允许作为条件输入 | 主线仅测量与几何；已知环境条件版本单列，禁止 GT 源掩膜泄漏 |
| 最终 test 是否在其他未同步实验中被使用 | 决定能否继续作盲测 | 目前仅依据所读仓库报告；执行前核对完整访问/实验登记 |
