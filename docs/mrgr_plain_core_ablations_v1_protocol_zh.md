# 普通集合交互最终架构双种子核心消融登记协议

本阶段只训练 GeometryLifting、单尺度 MRGR、无 PRF 三个消融，各用 20261011、20261019，合计六项。两个完整普通集合交互模型 checkpoint 和全部既有预测只校验复用。此前 OARI 架构的模块消融不作当前配对结果。

每项正式设置完全复制同种子普通交互基线，仅更新实验输出目录和分支标识。166训练、36验证；300 epochs、24900已提交优化器更新；batch2、AdamW lr2e-4/wd1e-4、cosine300、FP32、TF32关闭、clip1、原损失全部保留；每epoch保存last，仅验证投影H4严格最小值更新best，不早停。数据、几何与采样、种子、worker和checkpoint恢复使用未修改的正式引擎。

GeometryLifting：直接复用已登记 PlanarExtrusionLifting 类，64²探测平面双线性到32²，固定沿X挤出；主和残差两路同时替换，原可见性和几何描述符保留。此定义同时改变空间覆盖和深度结构，不能称纯算子因果估计。单尺度：直接复用正式 SingleScaleContext.forward，保持全部层/通道/参数，在32³执行三段卷积，删除池化和插值操作；无附加通道映射。无PRF：删除residual_encoder和residual_adapter，直接普通交互stage0输出，C0=C1，网络内不计算P(C0)，训练objective内所有原投影约束保留。唯一适配是将历史OARI stage0调用改为PlainSetStage0调用。

所有分支先由正式fresh普通交互工厂构建，再做无RNG的类替换或删除，保证保留参数和buffers与同种子fresh基线逐个相同，并检验构造后CPU RNG一致。此为实际工程测试结果，非假定；不读取训练后基线权重初始化。原CUDA grid_sample反向原子操作存在非确定性，不宣称训练轨迹逐位相同。参数数量及删除键精确登记。

工程：六项各CPU前向和结构/损失/初始化检查，各正式batch2 GPU前反向、clip、AdamW更新和checkpoint保存加载检查。工程模型不作为正式初始化或候选模型，不额外进行其他正式训练。正式训练前完成跨进程epoch-commit恢复检查（四例/两epoch工程子集，非额外科学训练）。工程失败保留证据、停止新启动、修复登记后再执行。

资源：重新核对GPU、进程归属、锁、主机内存与磁盘；UUID独占锁FD传给worker，间隔15秒双空闲快照。第一批仅Geometry和单尺度四项，最多四卡；第二批须第一批全部300轮、释放资源、基本验收后才启动两个PRF项。无空卡就等待，不共享其他任务GPU、不终止他人进程。不沿用旧阶段“先两项再扩展”限制：当前用户明确要求第一批最多四项，同时原主机资源门限保留。外部多fold父进程仍活跃时不利用其上下文空档，记录启动时占卡UUID及父进程，父进程退出后仍须双快照。持续快照检测外部CUDA冲突，若发生仅中断本阶段对应worker及其明确归属的数据子进程，保留last及日志，停止后续启动，按已授权故障恢复规则审计后从同一epoch commit恢复；不得静默重试或改预算。

六训练全部完成后冻结checkpoint、评价源码与配置；产生6×210=1260组新增C0/C1预测，复用2×210=420组基线预测。沿用35案例、普通Val-A-V4 draw0、clustered-V4 draw0..4，核验case/input IDs/input tensor hash/checkpoint hash/shape/dtype/finite/[0,1]及文件hash；1680组预测全局封存后才允许独立评价进程读取同35份已授权GT64，始终禁止GT128。GT不参与选轮和模型选择。用户本轮明确授权该范围，记录在注册产物中，不借用其他阶段授权。

指标直接调用正式volume_metrics/safe_shape：C0/C1相对L1/L2、峰幅比及绝对比例/幅度误差、峰值定位、两种正式质心定位、Dice50。每种子与同种子普通交互基线配对，Δ=ablation−full，误差指标正为变差；Dice正为改善。普通draw0、聚簇五draw案例内平均为主要两种布局，聚簇draw0另列。35案例、20000次配对bootstrap、seed20261026、均值百分位95%区间；同时均值、中位数、SD、增/降/数值不变(|Δ|≤1e-8)。不将draw或两个种子视作独立案例；案例区间不是跨训练种子区间，无等效性界限，无自动扩展训练搜索。独立计数权重与排序百分位复核统计。

成本：八个模型在同一独占GPU、验证案例0/17/34、固定普通V4、batch1 FP32/TF32关闭，逐例1 warmup+3测量，记录时间及峰值显存。每训练独立目录，源码、配置、初始状态、GPU、时间、实际更新、损失、LR、显存、资源快照和恢复留痕。最终中文报告如实回答三个模块贡献及种子/布局一致性，列出全部指标、成本、局限和最小后续验证。35案例已参与选择和诊断，本轮仅探索性消融；不能声称独立测试确认。只更新当前阶段追踪与轻量证据，不覆盖历史、不自动发布或推送。
