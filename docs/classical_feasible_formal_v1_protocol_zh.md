# 经典基线可行场预热、正式训练及测试 v1

2026-10-27（北京时间）。用户授权完成U-Net正式训练测试并自主调试其他失败算法。旧实验、主模型、历史NO_GO及main只读；使用新分支和scratch。

首先生成166个train案例专属自生成场：固定官方epoch0 A/B/H、原objective、64³/K96/全部有效射线，浓度初始常量为既有train测量确定c0，边界[0,1]，SciPy L-BFGS-B、FP64计算、每例最多60接受迭代/120函数求值/maxls10/maxcor5。最终FP32重算原目标。只读train测量，无GT/Val目标/PoolB/test，所有结果保留，不按Val或GT挑选teacher，不声称优化达到全局收敛。

U-Net从既有seed20261011尺度初始化规则fresh建立，不继承单案例记忆权重。完整166train/36Val、batch2、完整64³/全部有效K96、FP32、AdamW2e-4/wd1e-4/clip1。

阶段A固定60个完整train epoch，以每案例自生成场均方值归一化的A/B浓度MSE预热；每epoch采用原A/B随机采样，Val只计算原物理测量指标，不生成Val teacher。此阶段cosine T_max60，不用Val挑选中途预热权重，只取第60轮末态。阶段B从预热末态进入原完整objective，独立AdamW2e-4和cosine300，最多300epoch，每epoch83更新，总24900原目标更新；仅Val H选择best。预热4980更新及teacher求解预算另记，不冒充原协议等预算比较。

非有限数/零梯度/零参数变化立即保存现场停止；固定train0/1/2、Val0/1/2/3逐场输出及normal/zero/wrong-case干预监测。若阶段B第29/30轮均未达Val H≤.99且较fresh改善≥5%/绝对≥.01，或正常测量未在≥2/4个Val案例相对置零带来≥.001 H收益，不进入后270轮。异常塌缩连续两次监测则提前停止分析；正常波动保留日志。阶段A只设数值安全停止，避免将低初始std误判训练失败。若正式训练通过，固定best checkpoint及完整协议/源码/输入身份，再推理并封存官方35test全部既有17个layout（同主模型），最后独立进程读取GT64评分。测试GT不得用于重新选择训练协议或模型，GT128保持禁读。失败模型不伪报成功，允许另行固定一项有因果依据的修复，不无限搜索。

其他调试范围：DeepONet、FNO、Ray-Senseiver、Ray-GNOT、Ray-DeepSets。各自原架构fresh、相同合法测量尺度c0，末层残差权重缩小.01并bias置logit(c0)（DeepONet为branch输出缩小.01及独立bias置c0），不移植主模型。先每模型固定train0自生成场200步、再原目标200步，只取末态；评价E不进入训练/调参。成功后才计划多案例检查，失败保留梯度/场/测量证据并停止该候选。调试预算不能与U-Net正式性能排名混写。
