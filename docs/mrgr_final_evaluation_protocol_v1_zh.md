# MRGR论文最终评价协议 v1

执行计划见 [审计后的计划](reports/mrgr_paper_final_execution_plan_v1_zh.md)。本协议先于最终测试评分登记；机器注册位于 `outputs/research/mrgr_paper_final_v1/registration.json`，模型清单和布局表分别为同目录 `model_manifest.json` 与 `layouts.json`，均有SHA256侧文件。最终方法锁另外生成，全部开发实验完成前禁止正式预测与测试GT访问。

## 模型与数据边界

主模型为原多尺度MRGR，seed20261011，第278轮，344678参数，300轮，AdamW lr2e-4/wd1e-4、余弦300轮、梯度裁剪1、batch2。权重SHA256为650b4f2c0f0ab345b5fd99a7d629e0db388cede0937acb7e3191462cd57898d7。LR4E4是独立学习率对照，第291轮，SHA256为9c4436d6d5c3a5c27f96f60fec9f99d373822bad796771438baee79eda79f5ad，不替代主模型。

清单确认166训练、36开发验证、35保留测试。不能将历史开发验证称为最终盲测。网格为64³ XYZ端点、[0,0.6]³米，输出CH4质量分数[0,1]。输入观测单位ppm·m，训练集p99.5尺度32284.894580078173；测量归一化使用既有linear_p99_5。GT128始终禁止读取，测试GT64只在全部方法预测封存后由独立进程读取。

17组按普通固定V4、Spread-V4、V3 draw0–4、V6 draw0–4、聚簇V4 draw0–4顺序。普通V4使用ViewSampler(4,4,0,20261011)、epoch0、该split内source-index顺序；其余使用EvaluationViewSampler固定seed20261011。H4使用历史EvaluationWithHoldout，protocol精确为matched_条件名，保持历史规则。已在36例逐项复现输入/H4站位和顺序。最终35例同一规则生成并预先列入布局JSON。每算法595次重建；神经模型C0/C1共1190场，经典算法C1共595场。

## 前向和训练

P(C)在每条有效射线上取96个中点，先三线性插值质量分数C，再以g(C)=(C/16.043)/(C/16.043+(1−C)/28.965)转换摩尔分数，乘路径米与1e6。不得把结点摩尔分数线性插值当同一前向。经典主对照采用真实P(C)的有界非线性非负最小二乘、Tikhonov与平滑各向同性TV；历史SART只作近似算子背景证据。

训练使用原A/B/H不交叠采样：训练A/B各3–5站、H2，验证A4/B4/H4。损失为hold+0.5cross+0.1observed+0.05consistency；测量差异为归一化SmoothL1(beta0.01)+0.1相对L1。一致性项为两路预测绝对差的节点均值除以两路绝对浓度均值之平均加1e-6。H不进入网络输入。C0/C1是联合训练的两个阶段，仅用于轨迹诊断，消融使用独立训练。

消融方案：同参数量单尺度上下文（所有分支卷积留在32³，参数和层数完全相同，但FLOPs/有效感受野改变）；实际移除残差编码器/适配器且不计算反馈的无反馈模型；一致性系数置零。每个变体分别用20261011和20261019完整300轮，第二种子完整模型作配对参考，首种子完整模型复用冻结主模型。不得用GT选轮，仍按验证H相对L1严格最小选轮。所有模型新初始化，所有变体独立目录，单尺度与多尺度除尺度拓扑外不改其他配置。两种子可报告配对结果，但案例bootstrap不估计训练种子方差。

## 指标与统计

唯一主要终点：普通固定V4，最终C1，三维relative L1=Σ|预测−GT|/max(Σ|GT|,1e-6)。三维relative L2=sqrt(Σ(预测−GT)²/max(ΣGT²,1e-12))。保持现有volume_metrics及形态函数口径。报告35例逐例L1、均值、中位数、P90（numpy线性分位数）、最大值及所有预先列明对照的配对差。

次要指标：L2、每类布局L1/L2及P90、聚簇各draw、等权节点质心距离mm、全局峰比与|峰比−1|、GT argmax位置浓度比、Dice10/50、GT峰1%以下区域的背景预测占比、输入及额外H4投影L1/L2、每例计时、峰值显存、失败率。Dice对预测和GT都用同一案例GT峰的10%/50%阈值；GT阈值仅用于评价，不用于部署。物理体积分另用端点梯形权重，不能与等权节点质心混用。零预测质心等未定义量记null并报告有效例数，主终点仍计入该例。

V3/V6/聚簇先逐案例平均五draw，再跨案例统计；聚簇还报告各draw，35×5不当175个独立案例。配对bootstrap以35案例为单位，20000次，seed20261019，百分位95%区间。差值为主模型−对照，负值有利；对预登记的全部主要终点对照同时提供Bonferroni区间，只有校正区间上界<0才作对应改善声明。主要终点始终只有一个；次要结果均探索性，不作未校正确认性声明。

## 经典预算、失败和封存

有限选择：固定6个按训练source-index等距选取案例×普通/聚簇draw0，三方法各两候选，共72次。NNLS-NL比较100/200步；Tikhonov λ为1e-4/1e-3；TV λ为1e-5/1e-4，epsilon1e-4。零初始化、[0,1]约束；所有方法最多200步，至少40步，输入目标相对变化≤1e-5连续8次才提前停止；BB步长[1e-5,1e6]、Armijo1e-4、最多20次回溯、初始步1000。Tikhonov为物理前向差分平方，TV为平滑各向同性范数，外向导数置零。所有候选预测完成再读训练GT选择全局配置；随后36×17开发评价，最终方法全部保留，不按开发排名淘汰经典算法。

失败、异常值不得删除、补位或挑选有利迭代。未齐全部预测禁止读取最终GT；数值失败需在接触GT前明确处置并记入最终锁。测试阶段仅允许修复明确软件错误，保存旧日志、说明原因和影响，再生成版本化恢复记录，不修改超参数。GPU每次启动前按实时UUID、进程、显存及利用率选择，已有其他任务的设备不分配。训练按epoch原子保存权重、优化器、scheduler、RNG、loader状态、更新数和日志；经典算法保存BB步长、梯度、稳定计数和迭代轨迹，通过中断恢复测试后才启动正式预算。

最终锁包含全部权重/配置/源码/数据元信息和布局哈希、595次期望键及预算。先完成所有方法预测，再核验每个键、shape、非负范围、文件哈希，封存全体manifest；独立评分进程校验封存后方可读35份GT64。评分后不再训练或选模型。独立复核进程从封存数组重算主要指标与bootstrap，输出审核记录；图像预先取测试清单索引0/17/34，普通及聚簇draw0，相同GT峰切面、每案例统一色标，不按结果挑例。

## 成本解释与最终判读

神经重建秒数为同步C0+C1前向，不含加载、最终数组写入及额外投影；经典求解器秒数包含每20步恢复检查点的持久化I/O，几何准备及最终数组写入另列。完整worker和调度墙时另行保存。不得将不同计时边界的数值当作纯GPU计算速度比；显存同时保留Torch实际峰值与每15秒NVML进程采样峰值。

全部正式任务验收后，另生成[按预登记规则的最终结果判读](reports/mrgr_paper_final_interpretation_zh.md)，逐项区分Bonferroni区间支持的比较、跨零的比较、同种子消融方向及峰值/定位限制。未完成时该判读不生成，不能将当前开发表当最终结果。
